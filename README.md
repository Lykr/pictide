# Pictide

项目根目录为 `E:\Code\pictide`，前端模块 `web/` 的 npm 包名为 `pictide-web`；后端业务位于 `backend/`，产品名称为 Pictide。前后端职责及依赖方向见 [架构与模块边界](docs/architecture.md)。

本目录为独立 Git 项目根目录，协作步骤见 [Git 开发流程](docs/development.md)。`data/`、依赖和 `web/dist/` 不提交；从 Git 新检出后需按该流程安装依赖、构建前端，再启动应用。现有安装的本地构建产物保留。

画流 Pictide 是独立运行的本地图片工作台。ComfyUI 是可配置的生图后端，通过 HTTP API 接入；应用不加载到 ComfyUI，也不安装任何 ComfyUI 插件。

## 启动

双击 `start.cmd`，或在 PowerShell 执行：

```powershell
& 'E:\Code\pictide\start.ps1'
```

打开 http://127.0.0.1:8189 。关闭启动窗口或按 Ctrl+C 停止应用。没有自启动、计划任务或常驻服务；ComfyUI 与此应用可以独立启动、停止。

启动脚本会创建 `data/runtime/venv`，首次启动时安装 `requirements.txt` 中的 aiohttp。需要 Python 3.10+，可通过 `PICTIDE_PYTHON` 指定解释器（旧 `PICTIDE_WEB_PYTHON` 仍可读取）。本机也会尝试使用 Codex 已有的 Python 运行时。前端构建后由同一应用提供静态资源；日常启动不需要 Node.js 或前端构建服务，新检出目录需先构建一次。

```powershell
& '.\start.ps1' -Port 8189 -DataDir 'E:\PictideData'
```

### 局域网访问

双击 `start-lan.cmd`，或执行 `& '.\start.ps1' -Lan`。本机仍通过 `http://127.0.0.1:8189` 使用，其他设备通过启动窗口列出的电脑局域网 IP 访问，例如 `http://192.168.50.50:8189`；电脑 IP 变化后使用新地址。普通 `start.cmd` 保持仅本机访问。

Windows 首次使用需在管理员 PowerShell 添加防火墙规则，仅放行专用网络的本地子网：

```powershell
New-NetFirewallRule -Name 'Pictide-LAN-8189' -DisplayName 'Pictide LAN (8189)' -Direction Inbound -Action Allow -Protocol TCP -LocalPort 8189 -Profile Private -RemoteAddress LocalSubnet
```

电脑网络需为可信的“专用网络”，设备需处于可互通的局域网；不需开放 ComfyUI 端口。使用其他端口时同步修改防火墙规则。不配置路由器端口转发。

局域网启动监听 IPv4 所有接口，但 HTTP 仅接受本机回环地址或请求实际到达的本机内网 IP，保留同源修改校验。局域网设备共用图库、设置、任务和偏好，没有账号隔离，能够生成、评价及删除图片。只给可信设备开放。

手机使用底部导航，图片大图可左右滑动切换；沉浸模式提供触屏退出按钮。普通 iPhone 浏览器使用页面滚动并记住各栏目位置；地址栏收起仍由浏览器按内容高度和用户手势决定。主屏幕独立应用模式隐藏顶部品牌栏，保留栏目标题与系统安全区；保持固定外壳，图片和底部操作栏分别布局。普通 HTTP 下复制会尝试浏览器兼容方式，原生全屏不可用时使用页面内沉浸布局。

### iPhone 主屏幕应用

用 Safari 打开电脑的局域网地址 → 分享 → 添加到主屏幕 → 添加。若系统显示“作为 Web App 打开”，保持开启。从主屏幕的 Pictide 图标进入后使用独立窗口，不占用 Safari 地址栏，并复用现有底部导航与安全区布局。曾添加旧快捷方式时，需要移除旧快捷方式后重新添加，才能更新安装时的图标和窗口模式。

当前支持主屏幕启动、应用图标、独立窗口与主题颜色；没有 Service Worker 或离线缓存。电脑上的 Pictide 必须运行，手机需能访问该局域网地址；电脑 IP 改变后须使用新地址重新添加。无需 Apple 开发者账号。现代 iOS 可直接从主屏幕以 Web App 打开网页，具体安装入口与行为见 [Apple 使用说明](https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/ios) 和 [WebKit 主屏幕应用说明](https://webkit.org/blog/17333/webkit-features-in-safari-26-0/#every-site-can-be-a-web-app-on-ios-and-ipados)。

所有应用数据默认集中在项目下 `data/`：数据库、图片及提示词 JSON、日志、缓存、临时文件和 Python 运行环境。可用 `-DataDir` 或 `PICTIDE_DATA_DIR` 指定另一数据目录；旧 `PICTIDE_WEB_DATA_DIR` 仍用于保留自定义路径。详细布局与备份方式见 [数据目录](docs/data-layout.md)。数据目录已排除出 Git。

## 通用设置

「设置 → 通用」提供“跟随系统 / 简体中文 / English”语言选择，默认跟随浏览器首选语言，未支持的语言使用英文；切换立即生效并保存于 SQLite，同一应用的其他页面实时同步。界面语言不改变提示词、标签原名或用户命名。添加新语言的维护入口见 [国际化](docs/i18n.md)。

「设置 → 通用」提供“跟随系统 / 黑色 / 白色”主题选择，立即生效并保存于 `data/pictide.sqlite3`，刷新和重启后保留；同一应用的其他已打开页面通过实时事件同步。默认跟随系统，已有明确选择保留；系统外观变化实时生效，所有栏目及浮层共用主题。接口说明见 [通用设置](docs/general-settings.md)。

「设置 → 通用」提供默认开启的「图片切换动效」开关，控制漫游及生成／喜欢大图的淡入效果，刷新后保留；系统开启减少动态效果时不播放。详见 [通用设置](docs/general-settings.md)。

## 接入 ComfyUI

1. 启动 ComfyUI，打开 Pictide「设置 → 后端」，填写后端名称和实际地址，例如 `http://127.0.0.1:8188`。Desktop 的实际端口可能不同。
2. 保持“默认文生图”，读取并选择已安装的 checkpoint；留空自动使用列表中第一个模型，无需导入工作流或绑定输入。
3. 测试连接并保存，在「生成」页填写提示词并提交；「漫游」页专注浏览、评价与方向键操作。

内置工作流使用 ComfyUI 自带节点，适用于兼容 SD/SDXL 的完整 checkpoint，默认 1024×1024、28 步、CFG 5.5、DPM++ 2M / Karras、denoise 1。不会下载模型；Flux 等其他模型架构请使用对应的自定义工作流。

需要自定义流程时，切换“自定义 API 工作流”，导入 **API 格式** JSON，选择正负文本、可选种子和图片输出节点。普通包含 `nodes` 数组的界面工作流不适用。清空自定义工作流会回退默认文生图；已有非空工作流保留为自定义。

设置中的「工作流」将名称输入与下拉选择合并：可选默认文生图、已保存工作流或自定义 API 工作流，也可直接输入名称并筛选已有项。选择已有项后修改输入文字就是重命名，保留原 ID；选择自定义项会填写可修改的默认名称，并避免与已有名称重复。点击「保存后端」同时保存模板到 `data/workflows` 并应用到后端，无需单独另存或应用。保存时核对读取的修订号，外部修改冲突会保留草稿并阻止覆盖。新建自定义工作流时，同名同内容复用已有模板，同名不同内容拒绝保存。模板更新前的版本保存在 `data/workflows/.backups`。

工作流更新应用于本次保存的后端，其他后端保留各自已保存的工作流快照；重新选择工作流并保存可应用最新版。已有任务始终使用提交时的后端配置，不受后续编辑影响。

删除工作流会从选择列表移除并保留文件备份，同时解除当前后端对模板的引用；后端中已经应用的节点、绑定和输出快照保留，可以继续生成。删除后端只移除当前可选配置，原配置修订、历史任务、图片和评价保留；已提交任务继续使用原配置执行。删除操作不会清理图片或 ComfyUI 数据，恢复说明见 [数据目录](docs/data-layout.md)。

默认文生图的「节点参数」可展开为自定义草稿，支持模型、尺寸、批次数、采样步数、CFG、采样器、调度器和降噪等普通输入；连线保持不变。API 工作流 JSON 默认折叠，展开后可编辑或导入 API JSON，普通参数编辑与 JSON 使用同一草稿。

导入前请将工作流中的随机提示词生成节点替换为固定文本输入。平台把最终文本注入绑定的输入，工作流应将这些文本直接送入文本编码器，并保持输出提示词记录使用同一文本来源。不要在下游再次随机或改写文本，否则记录无法准确代表编码器实际输入。

ComfyUI 只执行生图 API，不再安装提示词生成、预览或提示词保存节点。工作流使用原生 PreviewImage / SaveImage 等图像输出，图片及对应的正负提示词 JSON 由 Pictide 保存。旧工作流如含已移除的 RulePrompt 节点，需要替换为原生文本输入和图像输出后再导入。

多个后端可分别保存。修改某个后端的地址或工作流后，旧任务继续使用提交时的后端配置，防止任务和图片指向错误的服务。新任务先订阅 ComfyUI 结束事件，再提交生图；全应用最多两个任务在途，通常一个出图、一个在 ComfyUI 排队；收到通知后通过 HTTP 核实，先补入下一项，再保存图片。通知不可用时自动回到轮询，详见 [任务事件通知](docs/task-events.md) 和 [提交窗口](docs/task-window.md)。生成完成后，Feed 将图片复制到 `data/images`，并保存同名 JSON，仅包含实际提交的正负提示词；不保存配置或额外 TXT。已保存图片可以在 ComfyUI 关闭后浏览。升级前的历史图片首次访问时补存，需要对应后端图片仍可读取。ComfyUI 自己的 output/temp 文件仍由 ComfyUI 管理。

测试连接执行只读预检，能发现常见的缺模型、缺输入图、连接或枚举错误；不提交生图，也不替代 ComfyUI 自定义节点的正式校验。HTTP 400 会展示可识别的节点及输入原因。

## 共现提示词候选

提示词候选根据 Danbooru 标签共现扩展生成。用户管理命名预设与固定正负提示词，词库是从数据集导入的只读数据；旧 JSON 标签库和槽位规则不再使用。数据来源为 `Shio-Koube/Danbooru-2026-parquet-metadata`，完整下载后在本地处理，不下载图片。设计、接口与 PMI 含义见 [共现候选说明](docs/cooccurrence-candidates-v1.md)。

提示词页面提供「词库 / 生成设置 / 预览」。词库包含普通 general 类别中出现至少 100 次的标签，以及 general / sensitive / questionable / explicit 四个图片评级标签，按原始名称分页搜索；生成设置编辑固定词、数量上下限、PMI 阈值、最低共现次数、屏蔽关键词及连续变化预算。固定词可从匹配列表选择或输入自由文本，列表标记「词库词 / 自定义」，编辑后自动重新识别；未匹配词保留输出但不参与统计。预览中悬停或聚焦词项可查看与当前组合其他词的 PMI 和共现次数，并联动高亮；自由词无统计与已知词对共现不足 10 次、未保留关系分别标记。

新词 t 必须对每个已有可统计标签 s 满足 PMI 阈值和最低共同次数。PMI 使用以 2 为底的对数，0 表示与独立预期相当，正值表示正关联；通过的词按 `2 ** mean(PMI)` 加权随机抽取；每次先在数量上下限之间等概率抽取一个整数作为目标，再尝试生成到该数量；无合格新词或搜索步数用尽时，直接返回当前已生成的提示词，可少于数量下限。数量包含固定正向词；固定词超过下限时，以固定词数量作为有效下限。不会为凑长度降低 PMI 或共现次数门槛；实际长度以生成结果为准。统计关联不是生成效果或无冲突保证。

随机模式每次使用新种子；固定种子可复现；连续模式按序列种子与帧序号衔接，标签增加和删除各算一次变化，替换算两次，预算 0 保持原组合。连续帧在数量上下限与预算可达范围的交集内均匀抽取目标数量；预算是上限，无可行变化时可以保持上一帧。因此连续帧的长期长度分布不保证全局均匀。保留种子 / 帧序号生成后控制和搜索上限，取消槽位维度的锁定、保持帧数等配置。

数据集内部按空格拆分标签，下划线连接词；词库界面显示原始名称，不保存显示副本；推荐和生图输出在内存中将下划线转空格，标签间用 `, ` 分隔。固定自由文本按完整条目保存，不按内部空格拆分。

成品仅保留共现次数 ≥10 的关系；缺失关系不代表零共现。评级可作为固定正向锚点参与统计。运行时词库原名、词频、PMI、共现次数、预设及数据来源保存在 `data/candidate.sqlite3`，导入素材在 `data/datasets/`。导入命令及分析依赖见 importer 的 CLI 帮助；导入在离线工具中执行，不放在启动或页面请求里。

## 当前功能

- 配置多个 ComfyUI API 后端，使用默认文生图或自定义 API 工作流。
- 默认、已保存及自定义工作流统一选择；保存后端同时保存命名工作流模板。
- 工作流原 ID 编辑与修订冲突检查；工作流和后端配置可删除，保留历史生成数据及恢复来源。
- 提示词页面统一管理只读词库、固定正负提示词与命名预设，支持共现参数编辑和候选预览。
- 共现候选模块支持随机、固定种子和预算连续序列；生图前可自动生成，也可先生成后编辑文本。
- 生成页支持每轮 1–10 次生图、连续 1–10 轮，结果在生成页独立展示；漫游只展示推荐预取的图片，喜欢可汇集两种来源。
- 手动提交确定提示词，绑定种子后可随机或指定图像种子；未绑定时明确使用工作流自身设置，不将请求中的随机值称为实际图像种子。
- 漫游、喜欢、任务、生成、提示词和设置共用唯一前端入口；图片可标记喜欢或撤回；漫游另支持不喜欢，与喜欢互斥。
- 任务记录持久保存在 SQLite 的 `jobs` 表；「设置 → 历史」的任务记录每页 15 条，按创建时间倒序排列，可上一页、下一页或输入页码跳转，实时更新保留当前页。
- 方向键操作：左键切较旧图片，右键切较新图片，上键喜欢，漫游下键不喜欢；输入框与设置窗口中不拦截方向键。键盘重复反馈不会撤回，按钮重复点击可撤回。
- 漫游支持沉浸模式：全屏展示图片，右上悬浮菜单按「播放/暂停、毛玻璃、退出沉浸模式」排列，底部操作栏按「上一张、喜欢、不喜欢、下一张」排列，毛玻璃与页面开关同步；静止约 2 秒后隐藏，鼠标、触摸或键盘操作唤醒，操作栏悬停或持有键盘焦点时保持显示，Esc 退出。浏览器不支持原生全屏时铺满页面视口。
- 漫游默认开启毛玻璃，漫游页右上角的毛玻璃按钮切换图片区域的模糊；本次页面内切图、切换类目保留状态，刷新恢复开启。仅改变画面展示，不修改原图或提示词。
- 漫游页右上提供播放/暂停，右上“漫游选项”与「设置 → 漫游」均可设置每张展示秒数（1–600，默认 5），共用 SQLite 配置。漫游页右上按「播放/暂停、毛玻璃、沉浸模式、漫游选项」排列；漫游选项包含展示时间、偏好范围、漫游方式与推荐力度，展示时间行不放播放按钮；这些设置也可在设置页调整，底部仅保留切图和评价按钮。图片加载完成才计时；下一张未生成则等待，到图后继续。离开漫游、切后台或刷新暂停，暂停不取消已派发任务。自动播放时点击喜欢或按 ↑ 暂停当前图，主动进入下一张后恢复播放并从加载完成重新计时；重复 ↑ 不再重置时间。普通与沉浸模式共用播放状态。
- 漫游保留上次观看位置；刷新页面或从喜欢返回仍展示该图。向右无图时按需生成，在漫游标题右侧显示加载图标，完成后自动前进；向左无图时停留。
- 漫游缓冲：按设置从共现候选生成较新图片，进入漫游、切图和状态更新时按需补足；最多两个未完成漫游任务，出图期间提前准备下一张提示词和评分；默认关闭自动预取，主动向右仍可请求新图，失败、取消漫游任务或结果不确定时暂停；修正并保存当前漫游使用的后端配置后恢复预取，也可重新保存完整漫游设置恢复，保留图片和任务，不自动恢复播放。
- 下载与图片对应的正负提示词 JSON。
- 历史图片懒清理：喜欢的图片保留，其余过期图片按需回收。
- 幂等提交、队列容量限制、任务恢复、提交结果不确定时核对而不自动重提。
- 生成页「取消待执行任务」一次取消全部仍为 `queued` 且未提交到后端的生成任务，不受当前页面列表数量限制；保留任务历史、提交中/运行中/状态待确认的任务与漫游预取。历史中的任务记录仍支持逐条取消，不调用全局 `/interrupt`。

**推荐第一版已实现。** 漫游候选组合由应用编排交给推荐模块评分，编排选择后提交任务。MiniLM 在 CPU 上按基础标签编码并缓存，用户喜欢/不喜欢分别以 +1/-1 更新组合关联，撤回移除对应证据，未评价保持未知。仅有完整生成快照的图片参与学习；缺快照的图片仍可保存反馈，但不推断标签来源。分数不是点赞概率，复杂搭配、参考图上传、图像特征与多用户登录仍未实现。详见 [推荐设计](docs/recommendation-v1.md) 与 [不喜欢反馈](docs/dislike-feedback.md)。

喜欢、不喜欢和撤回在反馈状态及待学习记录落库后返回；应用编排的单个后台任务处理推荐学习和本次反馈触发的清理，失败保留记录，启动及后续操作继续处理。新偏好稍后生效，已有预取保持；接口成功表示反馈已保存。详见 [后台偏好学习](docs/feedback-background-learning.md)。

「设置 → 漫游 → 用户偏好」可查看已学习标签的关联权重，或二次确认后重置。重置保留喜欢的图片、任务和标签库，只从此后的新反馈重新学习；历史反馈不会在重启或特征版本切换后自动恢复偏好。详见 [偏好查看与重置](docs/recommendation-preferences.md)。

推荐模型使用离线 FastEmbed 格式的 [MiniLM ONNX 模型](https://huggingface.co/Qdrant/all-MiniLM-L6-v2-onnx)，完整缓存目录 `models--Qdrant--all-MiniLM-L6-v2-onnx` 放在所选数据目录的 `cache/embeddings/` 下，包含 `refs/main` 和对应 `snapshots` 文件。应用不自动下载模型；模型或依赖缺失时保持生图可用，并在 bootstrap 的 `recommendation` 与漫游响应报告状态。应用启动脚本会安装版本化 CPU 依赖；此版本在 Python 3.12 上完成验证，较旧 Python 的兼容依赖由安装器选择。

## 词库与预设

词库来自离线导入，支持查看和选取，不提供新增、删除、启停标签或手动修改分类。固定正向词作为生成锚点，固定负向词独立输出；它们及生成参数保存在可编辑预设中。已有任务保存提交时的文本，编辑预设不会改写历史。

## 生成与图片来源

「生成」页分别设置「每次数量」与「生成次数」（均为 `1`–`10`，默认 `1`）。例如每次数量 `2`、生成次数 `3`，一次提交创建 3 轮、共 6 个独立任务，沿现有队列顺序执行。开启候选自动生成时，每轮重新抽取一次提示词，并按生成后控制更新候选种子与序列帧；同一轮内共用该轮正负提示词。固定控制保持不变；手动文本或关闭自动抽取时各轮沿用当前文本。标签库和后端配置在提交时冻结，后续编辑不改变已入队任务。

图像种子为 `-1` 时每个任务独立随机；指定种子时跨轮逐张递增，并在种子上限安全回绕，提交成功后输入框显示下一次种子。未绑定种子的工作流仍使用自身设置。全部轮次在后端一次入队，关闭网页或重启应用仍按既有任务恢复机制继续；候选生成失败或剩余队列容量不足时整批拒绝。任务队列最多保留 100 个待处理任务，多次提交共用容量。

数量表示工作流执行次数：默认单图工作流执行 N 次得到 N 张；自定义工作流若每次输出多张，所有输出均会保留，最终图片可能多于 N 张。整批通过容量和幂等检查后一起入队，剩余容量不足时不创建部分任务；网络重试复用原请求 ID 和整批输入。

生成结果在「生成」页的独立图片区域浏览和评价，不进入漫游列表或漫游缓冲计数。漫游只展示推荐预取任务的产物；「喜欢」汇集所有来源已喜欢的图片。喜欢页采用与生成页相同的缩略图网格；点击图片打开大图，支持左右切换、图片信息、独立毛玻璃（默认开启，空格切换）和沉浸模式。缩略图悬停或聚焦显示撤回喜欢按钮，撤回仍需二次确认；喜欢页不提供清空生成结果操作。旧版手动生成图片归入生成区，已有图片、提示词和评价保留，继续遵循统一历史清理设置。

生成结果采用缩略图网格，悬停或键盘聚焦显示喜欢按钮，触屏直接显示。毛玻璃默认开启，标题旁可切换；网格与点击图片打开的大图面板共享状态，刷新后恢复开启。大图操作栏按「上一张、喜欢、下一张」居中排列，毛玻璃按钮位于右上角关闭按钮左侧，图片信息靠最右，不展示图片删除和下载按钮。大图左右切换图片，↑ 喜欢，空格切换毛玻璃，下方向键不执行操作；也可进入自动隐藏操作栏的沉浸模式，Esc 先退出沉浸，再关闭大图。漫游图片也不展示原图下载按钮，信息面板保留提示词 JSON 下载。

标题旁一键清空作用于全部生成结果：未喜欢的图片及同名提示词 JSON 从本地清除，喜欢的图片仅移出生成结果，继续保留在「喜欢」。任务历史、ComfyUI 远端输出和漫游图片保留。操作不能撤回；文件被占用时沿用已有待删除队列重试。新生成的图片继续进入网格。

## 漫游缓冲

漫游图片下方提供可折叠的「画面锚点」，点选正向词保留画面元素，支持取消和清空；锚点跨刷新、重启保存，仅影响漫游。预设固定词标注「来自预设」且优先，重复项从锚点移除。增减锚点后保留当前图、清空旧预取；停泊时仅查看。详见 [画面锚点](docs/roam-anchors.md)。

漫游选项与设置页提供「推荐力度：标准 / 强力」。标准保留探索；强力按当前偏好均值评分，并把候选组合数量乘以强力倍数（1–5，默认 2，最多 100 组）。设置页调整倍数；切换保留当前图、预取和任务。两种力度共用偏好，停泊已有组合时直接复用。详见 [推荐力度](docs/roam-recommendation-strength.md)。

「设置 → 漫游」可设置候选组合数量（1–20，默认 4），每次从这些完整组合中推荐择一生图；数量越大，准备耗时通常越长。修改只影响新准备的组合，已有预取和任务保留。停泊已有参考组合时直接复用。详见 [候选组合数量](docs/roam-candidate-count.md)。

「设置 → 漫游」保存缓冲数量、后端、候选预设、自动播放间隔、偏好范围与漫游方式；漫游右上菜单提供相同选项，修改同步且保留其他草稿。偏好范围为「全部 / 喜欢」；漫游方式为「漂流 / 顺流 / 停泊」，默认漂流。顺流按候选预设变化预算从实际选中组合继续，停泊保留整组提示词，图像种子仍随机。切换范围、方式、后端或预设时保留当前图，清空其后旧预取、取消旧待执行漫游任务，迟到结果不再进入漫游；喜欢、文件及生成页任务保留。详见 [漫游方式](docs/roam-modes.md)。缓冲数量为 `0`–`20`，默认 `0` 关闭自动预取，已有安装升级后也不会自动开启生图；`N` 表示当前图片右侧较新漫游图片的目标张数，空漫游列表需要先生成首张，再补足 `N` 张。批量工作流按实际返回并入库的漫游图片计数，不按任务数计算；生成页图片不计入缓冲。

同页的「历史图片数量上限」设置当前观看位置之前最多展示的漫游历史图片总数（`0`–`100000`，默认 `0` 关闭数量清理）。例如设置为 `100`，当前位置之前的所有可见漫游图片都计入上限，超额按入库时间从最早的图片开始处理：未喜欢的清除本地图片及同名提示词 JSON，喜欢的只从漫游隐藏，继续保留在喜欢页。生成页图片不受影响。保存立即检查，之后在启动、浏览、生成和评价等操作时按需检查，不增加定时任务。清理后观看位置按既有邻图规则恢复；已经隐藏的图片不会因撤回喜欢重新出现在漫游。

数量上限只计算当前图片之前的全部可见历史，当前图片和后面的预取图片不计入，不调整预取数量。保存观看位置后按新位置检查，未保存位置时不进行数量清理；已喜欢图片超限时仅从漫游隐藏，原文件及提示词保留。时间清理设置与数量清理分别生效，大量超限时每次最多标记 100 张，后续操作继续回收。

漫游观看位置保存在 SQLite，刷新页面、切换到喜欢再返回或重启应用后继续观看该图；喜欢和生成页的选图不会覆盖漫游位置。旧图不在最近列表中时读取其附近图片，仍可连续向前、向后浏览；原图被清理后恢复到邻近的可用漫游图片。

沉浸模式沿用同一张图片、观看位置、毛玻璃状态和按需加载流程；切图、喜欢和方向键操作与普通漫游一致。退出沉浸或离开漫游后恢复正常页面布局，不改变原图。

向右没有图片时请求生成，等待期间显示加载动画，图片就绪后自动前进一次，不显示「最新一张」提示；`N=0` 也支持这次主动请求，但不会因此开启后续自动预取。空漫游可点击开始按钮请求首图。向左没有更旧图片时保持原图，不生成过去的图片。离开漫游会结束本次界面等待，已提交的任务继续执行；失败或暂停时停止动画并显示原因。

后端留空使用当前首个后端，标签库留空优先使用 `default.json`，否则使用首个标签库；开启缓冲时，显式选择会在保存时检查是否存在。设置为 `0` 时跳过存在性检查，即使选中的后端或标签库已删除，也可以关闭补图。漫游使用已保存标签库中的规则生成随机候选，不使用「生成」页尚未提交的文本或草稿。

进入漫游、切换图片和收到状态更新时，浏览器调用补图接口。后端依据数据库中的图片和任务状态检查缓冲，并在锁保护下每次至多提交一个预取任务，最多保留两个未完成漫游任务，让出图与下一张提示词准备重叠；达到缓冲目标或队列容量时等待后续事件。预取没有独立定时器、生图循环或启动后自行投喂；自动播放的计时仅触发既有下一张操作。离开漫游或关闭页面后，已经提交的任务仍可完成。

网络断连、HTTP 408/429/5xx 等暂时请求错误不会永久锁住浏览器预取；后续成功刷新、SSE 重连或回到漫游等既有事件可再次检查，成功后清除临时错误提示，不增加重试定时器。后端明确报告的预取失败、取消本次设置下的漫游任务或提交结果不确定时仍暂停当前设置版本的补图，保存漫游设置可解除暂停；手动任务取消和旧设置版本的漫游任务失败不会暂停新版本。设置保存于 主 SQLite 的 `roam_settings` 表，任务归属、候选标签历史快照与暂停状态保存于 SQLite。图片旁提示词 JSON 仍只含实际提交的正负文本。

## 历史图片清理

「设置 → 历史 → 图片清理」设置未标记喜欢的图片保留天数，默认 **1 天（24 小时）**，`0` 关闭新的过期清理。期限从图片完成并进入 Feed 起计算；任意用户已标记喜欢的图片受到保护，其余过期图片按需清理。取消喜欢后仍按原入库时间判断，已经过期的图片可能在下一次触发时移除。

应用启动、读取图片列表或图片、提交生图和评价时按需检查；保存设置立即执行一次检查。没有定时任务、清理轮询或独立后台服务。时间过期检查至少间隔 60 秒，开启的漫游数量上限在这些操作中继续检查，避免新图片在间隔内持续超限；两种清理合计每次最多标记 100 张并回收 100 组待删除文件，避免大图库阻塞操作。未打开应用或没有触发操作时不执行清理。

清理移除 Pictide `data/images` 中的图片及同名提示词 JSON，Feed 同步隐藏；生成记录、评价历史和防重复提交记录保留。ComfyUI 远端文件、配置、标签库及备份目录不受影响。已清理的图片不能通过旧链接或重试任务恢复。

文件被占用或暂时无法删除时，待删除记录持久保存在数据库，下次触发继续回收；即使关闭新的过期清理，先前已确定删除的文件仍会重试。路径越界、符号链接及 Windows Junction 均拒绝删除，活跃图片共享的文件及 JSON 也受保护。设置保存在 `data/history-cleanup.json`；设置文件损坏时暂停新的过期清理，可以在窗口重新保存修复。

## 提示词与候选

候选模块先提供完整正负提示词组合；应用编排把全部候选交给推荐评分，再选一个完整组合提交任务。候选、推荐、任务之间不直接调用。漫游使用已保存的共现预设，手动生成保留直接输入提示词的入口。

候选数据读取与预设编辑使用 `/api/candidate/tags`、`/api/candidate/presets`、`/api/candidate/dataset`；预览使用 `/api/candidate/generate`。模块接口与连续语义统一维护在 [共现候选说明](docs/cooccurrence-candidates-v1.md)。


入口运行 `python -m backend.host`。HTTP 宿主通过应用编排调用候选、推荐、任务和存储；任务通过生图接口接入 ComfyUI，并将结果写入存储。完整架构图、依赖规则与未实现能力见 [架构说明](docs/architecture.md)。

前端通过 HTTP API 和 `/api/events` SSE 接收数据与变更通知；连接不可用时保留轮询回退。事件复用既有任务变化及应用操作，不另增生图调度循环。扩展新的生图服务时实现统一 `generation` 接口并注册；候选和推荐不依赖 ComfyUI，推荐状态不修改只读词库或生成预设。

## 前端开发与设计

页面统一采用 shadcn/ui 的用户预设 `b1VlIttI`（Radix Luma / Neutral / Inter / Lucide），预设记录在 `web/shadcn-preset.json`。Inter 字体本地打包，常规控件沿用预设尺寸。后续页面及组件变更遵循 [页面设计规范](docs/design-system.md)，第三方来源见 [组件声明](web/src/THIRD_PARTY_NOTICES.md)。共享主题在 `web/src/styles/theme.css`，基础组件在 `web/src/components/ui/`。

唯一入口 `web/index.html` 加载 `web/src/main.tsx`。Feed 和提示词编辑器由共享 React 应用壳层与现有 JavaScript 控制器组成，通过内部视图切换保留草稿；标签库和生成业务逻辑留在后端候选模块。前端使用 React、TypeScript、Tailwind CSS 和 Vite。在 `web/` 目录执行：

```powershell
pnpm install --frozen-lockfile
pnpm run typecheck
pnpm run build
```

使用 `web/package.json` 声明的 pnpm 版本和 `web/pnpm-lock.yaml` 锁定依赖。构建输出为 `web/dist/`，由 HTTP 宿主提供；无 CDN、远程字体或额外 Node 服务。不要直接修改生成资源。正常使用运行项目根目录的启动脚本即可。

前端依赖实体位于项目根目录 `data/runtime/frontend/node_modules`，包仓库与下载缓存位于 `data/cache/pnpm-store`、`data/cache/pnpm`；`web/node_modules` 是指向依赖实体的 Junction。Vite 缓存位于 `data/cache/vite`。这些是源码构建环境，使用项目根目录的 `data/`，与运行时指定的数据目录分别管理。前端入口和生命周期说明见 [Web 模块说明](web/README.md)。

## 数据与推荐契约

候选输出完整组合和 `TagSnapshot`，来源标识包含数据集版本，文本使用实际输出的空格形式，正负方向单独记录。推荐仍根据文本内容与正负向编码，不依赖只读词库 ID 或类别。历史图片使用生成当时的组合快照，不通过当前词库重解释；新增、更新数据集不改写原任务、图片和反馈。

共现统计提供候选生成先验，用户喜好独立保存在推荐模块。具体边界与版本规则见 [推荐设计](docs/recommendation-v1.md) 和 [共现候选](docs/cooccurrence-candidates-v1.md)。

本项目已从 ComfyUI 工具仓库拆分为独立 Git 仓库。原源码历史保留在旧仓库，新仓库从当前可运行版本建立初始快照；`data/` 和构建产物不进入版本管理。迁移记录、运行环境版本和历史清理待确认清单在 `data/maintenance/`，当前服务仍使用 8189 端口。历史数据未获确认前保留。

共现扩展的“屏蔽关键词”每行一项，按包含关系跳过命中标签，忽略大小写并将空格/下划线视为等价；只影响新抽取的正向标签，固定正负词和停泊已有提示词保留。规则随候选预设保存，详见 [屏蔽关键词](docs/candidate-blocked-keywords.md)。

## 喜欢页标签筛选

喜欢页可搜索并多选图片历史正向词项，只展示同时包含全部已选词项的喜欢图片。标签默认字典序升序，排序图标切换为图片数量降序、同数量字典序升序；数量统计全部喜欢图片，同图同词只计一次。详情与接口见 [喜欢页标签筛选](docs/liked-tag-filter.md)。

任务记录集中在「设置 → 历史」，保留分页、详情与逐条取消；图片清理设置在同页的折叠区。数据目录及数据库路径集中在「设置 → 通用 → 数据位置」，侧栏不再单列任务栏目。
