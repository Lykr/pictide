# 设计文档模板

开发前提交的设计按以下结构呈现，重点是变更项。架构图展示涉及变更的组成及依赖，调用和数据流图展示模块间的交互与数据流动；职责边界优先通过接口表达。概述尽量一句话，避免过多阐述已有逻辑和防御性逻辑。

````markdown
# 标题

## 概述

尽可能简要描述需求和变更，能用一句话，不用多句话。

## 架构

```mermaid
涉及变更的架构图
```

## 职责边界

变更的架构中不同组成部分的职责边界，通常是接口的方式呈现。

## 调用和数据流

```mermaid
涉及变更的模块间调用和数据流
```

## 重点关注

- 事项 1
- 事项 2
````
