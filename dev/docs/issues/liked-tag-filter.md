# 喜欢页标签筛选

状态：已实现；存储／HTTP 与前端冒烟、类型检查、构建和浏览器验证通过。替代此前待确认的收藏夹方案；不实现收藏夹。

## 页面与行为

- 喜欢页增加可搜索、多选的标签筛选器，选择多个标签时匹配同时包含全部标签的图片（AND）。清空选择展示全部喜欢。
- 标签默认按字典序升序；本设计将「开始排序后」解释为点击排序图标后切换到图片数量降序，同数量按字典序升序，可再切回字典序。
- 筛选列表每批展示 50 个标签，使用共享按钮加载更多；打开、搜索或切换排序时恢复首批。搜索覆盖全部标签，排序只在数据或排序方式变化时重算。
- 搜索只按文字匹配缩小标签列表；大小写不敏感，不改变已选择项。已选标签显示为可单独移除的紧凑项。
- 每个标签显示对应的喜欢图片数量：统计全部未删除的喜欢图片，不限已加载页，不随当前已选标签改变。同一图片同一标签只计一次，任务输出多张图分别计数。
- 只使用历史保存的正向提示词，按逗号分隔为完整词项，去除首尾空白和空项，保留完整词项文本；不按空格拆词、不做语义推断或读取当前词库。自由描述没有逗号时作为一个完整词项。此最小方案同时覆盖漫游及手动生成的历史图片；负向词不参与筛选项。
- 字典序按原文的稳定字符串顺序处理；搜索大小写不敏感，但不同原文不自动合并。每张图片保存的历史输出是筛选依据，筛选不代表图像识别结果。
- 图片列表由服务端筛选后再做既有游标分页；total、has_more 与游标针对筛选结果计算。大图左右切换限当前筛选结果。
- 更换筛选清空当前图片窗口并从首批读取，旧请求结果不合入新筛选；取消喜欢后同步标签计数和当前结果。分类筛选不触发额外学习。
- 保留毛玻璃、独立滚动、网格 cover、大图 contain 与现有取消喜欢二次确认。复用 shadcn Popover/Command/Checkbox、Badge 和图标按钮。

## 架构及调用链

浏览器 → Host → PictideApplication → Storage → SQLite。

沿用现有模块，不新增业务模块，不调用候选、推荐或任务模块。标签索引是喜欢页查询用的内存数据，不作为推荐特征，也不改写历史提示词。

- 加载筛选器：Host 接收标签列表请求 → 编排读取 Storage.liked_tags → Storage 从当前喜欢图片关联的 jobs.positive 汇总历史词项及逐图数量 → 返回标签与现有 artifact_revision。
- 加载图片：Host 读取重复 tag 参数 → 编排校验 → Storage.artifact_page 按喜欢状态及所有 tag 过滤 → 既有分页响应 → 喜欢网格及大图。
- 修改喜欢反馈：沿用现有反馈与 SSE 事件，前端刷新标签计数和当前筛选结果。读取操作不产生学习证据；推荐仍按既有图片反馈运行。

## HTTP 接口

新增只读 GET `/api/liked/tags`：

```json
{"tags":[{"text":"black hair","count":12}],"revision":123}
```

返回所有当前喜欢图片中出现的正向历史词项；默认字典序升序。首版搜索与数量排序在浏览器处理，不新增服务端搜索或排序参数。

扩展现有 GET `/api/artifacts`，仅 `liked=1` 接受重复 `tag` 参数：

`/api/artifacts?liked=1&tag=black%20hair&tag=glasses`

输入为完整词项的精确匹配，重复值去重；不传 tag 保持原行为，非喜欢查询携带 tag 返回 400。返回结构保持现有 artifacts、total、has_more、next_cursor、revision 等字段。图片仍按既有时间倒序排列，标签列表排序不改变图片顺序。

## Storage 接口

- 新增 `liked_tags() -> list[dict]`，项为 `{text: str, count: int}`。
- 既有 `artifact_page(...)` 末尾新增 `tags: tuple[str, ...] = ()`，AND 筛选；应用编排的 artifacts 方法同步增加可选 tags 参数。
- 词项拆分与匹配作为 store 内部共享函数，统计和图片筛选使用同一规则。复用 SQLite 历史记录，首版不建索引表、不迁移、不改写应用数据库。
- 若使用查询内部缓存，仅允许以现有 artifact_revision 失效，不引入后台刷新；当前 PoC 可直接按喜欢记录读取并统计。

## 验证与发布

- 少量存储冒烟：同图重复词计一次、多图计数、只统计喜欢正向词、AND 筛选、自由描述完整保留、筛选后的游标分页。
- 少量前端冒烟：多选／取消／清空、字典序／数量排序及同数并列顺序、搜索不丢已选、旧响应不覆盖新筛选。
- 类型检查与构建、独立模拟数据浏览器验证；生产图片与偏好不用于写入测试。
- 发布先备份旧前端；后端新增接口需要重启，先通知并核对运行中的任务，保留任务和草稿。
