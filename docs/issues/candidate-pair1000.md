# 共现 ≥1,000 次的极限裁剪

## 概述

2026-10-19 按用户要求，将运行词库裁剪为只保留共现 ≥1,000 次的关系，保留全部标签、频次、PMI 与预设原值。

## 数据处理

从 SQLite 一致性备份创建新库，复制全部 tags/dataset/presets，仅复制 correlations 中 count ≥1,000 的行，重建原索引并生成 SQLite 统计信息。PMI 仍基于原始全量图片统计，关系裁剪只影响保留范围。基础 importer 继续生成 ≥10 次的完整统计库，本次精简产物由该成品裁剪。

| 项目 | 裁剪结果 |
| --- | ---: |
| 标签 | 21,542 个，保持 |
| 原关系 | 13,915,101 条 |
| 保留关系 | 622,439 条 |
| 原数据库 | 483,188,736 B（460.8 MiB） |
| 裁剪数据库 | 23,220,224 B（22.1 MiB） |
| gzip 产物 | 12,084,683 B（11.5 MiB） |
| 孤立标签 | 13,550 个（62.9%） |
| 剩余 1–5 个关联的标签 | 1,665 个 |

运行时沿用原始标签 ID 和预设。现有 min_cooccurrence 设置保持，低于 1,000 的数值只能查询已经保留的关系；较高的设置继续过滤。候选来源标识沿用基础导入来源，具体裁剪范围以本记录和实际关系为准。

## 展示与接口

预览表头统一为「共现次数」，已知词对缺记录时仍返回 pmi/count=null，显示「未保留统计 / —」；自定义词继续显示「无统计」。通用展示适用于不同裁剪范围，HTTP 字段和调用链保持。

## 验证

SQLite 完整性检查通过；标签、来源和预设与备份双向比较一致；保留关系的 PMI 和共现次数与原库一致，最低共现次数为 1,000。

对未固定锚点、人物锚点（general/1girl/solo）和风景锚点（general/scenery）各使用 8 个固定种子、目标 15–30 个标签做小样本比较：

| 锚点 | 原库平均长度 | 精简库平均长度 | 精简库低于 15 个的样本 |
| --- | ---: | ---: | ---: |
| 无 | 21.38 | 17.38 | 2/8 |
| 人物 | 19.12 | 14.50 | 3/8 |
| 风景 | 21.38 | 14.62 | 3/8 |

同种子复现与连续三帧变化预算检查通过。部分组合因候选用尽提前结束，仍返回有效组合，沿用已有生成行为。样本用于验证裁剪后的生成路径，实际生图质量需要另行观察。

前端类型检查和构建通过；预览相关性展示通过独立实例验证。此次执行候选生成与界面冒烟，真实 GPU 出图效果待观察。
