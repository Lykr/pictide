# Pictide 页面设计规范

适用于图片 Feed、提示词编辑器、设置与后续新增页面。目标是简约、紧凑、层级清晰，主要空间留给图片、提示词与正在编辑的数据。

视觉基准固定为用户提供的 [shadcn Create 预设 b1VlIttI](https://ui.shadcn.com/create?preset=b1VlIttI)：Radix Luma、Neutral 配色、Inter 字体、Lucide 图标、默认圆角，菜单使用 default / subtle。预设记录在 `web/shadcn-preset.json`，生成器配置在 `web/components.json`。不再以笼统的“类似官网”作为验收标准。

## 提示词领域命名

- 标签（tag）是数据集中的完整描述，词库只读；词库包含普通描述标签与从图片 rating 转换的 general / sensitive / questionable / explicit 评级标签，不展示角色 / 作品 / 作者分类。
- 预设包含用户固定正负词与共现生成参数，存于 SQLite。提示词页依次使用「词库」「生成设置」「预览」，不再展示可编辑标签库或槽位。
- 「生成设置 → 共现扩展」提供共享 Textarea「屏蔽关键词」，每行一个，复用字段标题与 HelpTip；多行草稿保留换行，保存和预览使用去空行、去首尾空白及去重的关键词列表。帮助明确包含匹配、忽略大小写、空格／下划线等价，仅限制新抽取标签；固定正负词与停泊保持的提示词不重新过滤。
- 固定词支持自由输入并回车添加、方向键/点击选取匹配项、编辑和移除；左侧手柄支持拖拽排序及 ↑/↓ 键排序，右侧移除按钮与输入框展开按钮同列对齐；无匹配的自由文本可保存，明确说明不参与共现计算。固定词输入框右侧以共享 Badge 标记「词库词 / 自定义」，按完整文本匹配词库（空格与下划线等价），编辑后重新识别；查询期间与失败分别显示「识别中 / 未识别」，不把查询失败当作自定义词。复用已有只读相关性接口的 known 字段，不改变预设结构。连续配置只保留标签变化预算；界面复用既有 shadcn 组件与主题。

## 技术与维护入口

- 基础组件采用 [shadcn/ui](https://github.com/shadcn-ui/ui) 的源码组件，保存在 `web/src/components/ui/`；页面使用 React、TypeScript 与 Tailwind CSS，由 Vite 编译为静态资源。
- `web/src/styles/theme.css` 是颜色、字体、尺寸与基础交互样式的唯一维护入口；页面布局分别放在 `web/src/styles/feed.css` 和 `web/src/styles/editor.css`。
- Feed 与编辑器共用页面入口 `web/src/main.tsx`，内部视图组件为 `web/src/feed.tsx`、`web/src/editor.tsx`。现有 JavaScript 控制器继续处理业务状态、接口、动态列表与表单；动态 DOM 通过 `web/src/dom-primitives.ts` 复用共享组件的样式配方。这次统一包含 React 页面壳层和组件接入，尚未把全部业务控制器改写为 React。
- 可见下拉菜单、复选框、单选、分段切换、弹窗及折叠区域复用官方 `radix-luma` 源码组件和 Radix 行为，不使用原生菜单或自行开发交互。DOM 控制器通过共享状态适配层接入组件；隐藏状态接口不是可见 UI。新控件同时验证展开样式、键盘、表单提交、焦点与禁用继承。
- Node.js 仅用于开发构建。发布的静态资源由现有 aiohttp 应用提供；正常启动不需要 Node 服务、CDN、远程字体或额外前端进程。

新增基础组件先查现有源码，再按 [官方 Vite 接入说明](https://ui.shadcn.com/docs/installation/vite) 引入需要的组件。引入时使用 `radix-luma` 样式，保留预设配方，并更新 [第三方声明](../web/src/THIRD_PARTY_NOTICES.md)。不要手工编辑构建产物。

项目使用 pnpm，按 `package.json` 的 `packageManager` 版本和 `pnpm-lock.yaml` 安装。重新应用预设先在副本运行 `pnpm dlx shadcn@4.21.4 apply --preset b1VlIttI -y` 并核对差异；保留动态 DOM 所需的样式配方导出，不直接覆盖业务适配。新增组件可运行 `pnpm dlx shadcn@latest add <组件名>`；检查生成的别名，将共享工具导入统一为 `@/lib/utils`，避免升级生成器时引入第二套工具函数或主题。

## 视觉基础

使用预设的浅色 Neutral 主题、Luma 胶囊按钮与柔和填充输入框。浅色与深色复用官方 token；「设置 → 通用」提供共享 ToggleGroup 单选分段控件（跟随系统 / 黑色 / 白色），默认跟随系统，立即切换并保存到应用 SQLite。页面挂载前读取已保存主题；system 通过 prefers-color-scheme 实时解析，明确选择黑白主题时保持固定，不在浏览器 storage 另存副本；所有栏目和浮层跟随根节点主题。

| 项目 | 约定 |
| --- | --- |
| 正文字号 | 14px，行高约 1.5；辅助说明 12px，业务表格可紧凑展示 |
| 标题 | 页面 20px、分区 16px、卡片/字段组 14px；以字重区分层级 |
| 字体 | Inter Variable 本地打包，中文使用系统回退；代码、ID、提示词原文使用共享等宽字体 token |
| 间距 | 4px 基础刻度：4 / 8 / 12 / 16 / 24 / 32px |
| 控件高度 | 预设默认 36px；必要的次级操作显式使用 sm（32px），不全局覆盖组件高度 |
| 圆角 | 采用官方预设的圆角尺度；按钮、输入框、文本域保留各自 Luma 配方，禁止统一强制为一个圆角 |
| 边框与阴影 | 1px 边框区分分区；浮层使用轻阴影，常规卡片避免厚阴影 |
| 动画 | 仅用于悬停、焦点和状态反馈；短时过渡，遵循减少动态效果偏好 |

颜色通过语义 token 引用，遵循 [shadcn 主题约定](https://ui.shadcn.com/docs/theming)。主题值以源码为准，本说明不复制色值。

| Token | 用途 |
| --- | --- |
| `background` / `foreground` | 页面底色与主要文字 |
| `card` / `card-foreground` | 卡片、面板 |
| `popover` / `popover-foreground` | 弹窗、浮层 |
| `primary` / `primary-foreground` | 当前区域的主要操作 |
| `secondary` / `secondary-foreground` | 次要操作和辅助容器 |
| `muted` / `muted-foreground` | 次要信息、占位、说明 |
| `accent` / `accent-foreground` | 悬停、选中背景 |
| `border` / `input` / `ring` | 分隔、表单边框、键盘焦点 |
| `destructive` | 错误与删除操作 |
| `success` / `warning` | 成功与警告状态 |

业务状态使用共享状态样式与语义颜色，并配合文字或图标。成功、等待、错误、禁用不能仅用颜色区分。页面 CSS 不新增同义色板。

## 组件使用

### 按钮

| 变体 | 用途与例子 |
| --- | --- |
| `default`（主按钮） | 提交当前任务：生成图片、保存后端、保存配置 |
| `secondary` | 次级操作：生成候选、预览 |
| `outline` | 一般工具操作：导入、导出、测试连接 |
| `ghost` | 导航与低强调操作：返回、关闭、更多 |
| `destructive` | 明确删除或不可恢复操作 |
| `link` | 查看帮助、跳转文档 |

同一操作区通常只放一个主按钮。保存、生成、确认等主操作保留短文字；新建、复制、刷新、关闭、排序、下载、切图等常用工具使用统一 Lucide 图标按钮。导航保留短名称配图标，不把所有字段标签和导航都变成只有图标。加载时显示正在执行的动作并阻止重复提交；完成或失败后恢复可操作状态。

图标按钮复用 `web/src/components/actions.tsx` 的 `IconButton`（默认 `ghost` / `icon-sm`），必须有明确中文 `aria-label` 与悬浮提示。控制器拥有的动态按钮复用 `dom-primitives.ts` 的 `setAction` 和相同 Lucide SVG 数据；更新动作状态时同步可访问名称和提示，不能用 `textContent` 清除图标。避免使用 Unicode 箭头、加号或 emoji 替代操作图标。

### 文案与按需帮助

- 常态只展示任务标题、字段标签、当前值、简短状态和必要动作。删除重复标题、品牌副标题、技术实现说明和反复出现的“已加载”“本地文件”“不调用 LLM”等文字。
- 每条悬浮提示只解释当前对象或操作，优先一至两句。选项含义放在选项自身，输入方式放在输入框，匹配/来源/排序/保存说明各归对应控件；分组帮助只说明共同规则，不重复列出全部选项。背景原理等长说明保留在所属文档或现有详情中。
- 参数含义、默认行为、快捷键和操作后果通过 `HelpTip` 或 `data-tooltip` 按需显示；不在每个输入框下面常驻一段说明。空状态只保留一句引导和一个下一步操作。
- 复用 Radix Tooltip，React 和动态 DOM 共用一个提示层。悬停或键盘聚焦显示，帮助图标支持点击及 Enter / Space，Escape 关闭；提示与官方 Dialog、Select 等浮层正确叠放，不创建另一个页面入口或 React 根节点。
- 错误、校验失败、保存冲突、未保存状态、当前任务进度必须保持可见。删除范围与不可恢复的后果不能只藏进悬浮提示。
- 长路径、后端详细信息和规则说明放入悬浮提示或现有折叠区域；不为了缩短页面移除业务功能、表单约束或草稿保护。

```tsx
<Button disabled={!dirty || saving}>保存配置</Button>
<Button variant="outline">导出</Button>
<Button variant="ghost">取消</Button>
```

### 表单与编辑

- 字段标签在控件上方，必要说明通过字段标签附近的帮助图标展示；用 `label` / `htmlFor` 关联输入。占位符只举例，不代替字段标签。
- 字段组优先用 8–12px 间距，分区之间用 16–24px；标签编辑中类目和抽中权重并排，依赖、互斥和标识使用轻量折叠行。帮助按钮统一 ghost / icon-xs，不附带外框；独立滚动区域保留明确边界。
- 工作流使用同一可编辑组合框管理选择与名称，复用 Command / Popover；输入改名保持所选 ID，选择自定义项提供默认名称。不要另外增加名称输入框。已有密钥仅显示固定遮罩，清空并保存表示移除，不使用独立的清除复选框，也不把真实密钥返回浏览器。
- 工作流参数只有一个面板：标题「节点参数」右侧放 JSON 切换与导入按钮。默认展示普通参数，JSON 模式在同一位置替换内容；两种视图共享草稿。无效 JSON 保留在编辑器中并显示错误，修正后再返回参数视图；导入替换同一草稿并同步有效绑定。
- 字段错误显示在对应输入附近，并通过 `aria-invalid` 与说明关联；全局错误显示可执行的原因，避免仅提示“失败”。
- 原生数字输入同时设置输入限制和业务校验；前端限制不能代替服务端校验。
- 切换随机/连续模式时只显示当前模式需要的字段；共享参数仍保持可见。隐藏参数不应丢失草稿。




### 分页

- 词库、任务及用户偏好的页码分页统一复用 `web/src/components/page-controls.tsx`，默认每页 15 条；不在页面另写分页控件或独立样式。
- 底部居中排列：上一页图标、页码输入框、总页数、跳转图标、下一页图标。统一使用共享 shadcn Button / Input，输入框和按钮均为 32px 高。
- 输入有效整数页码后点击跳转或按 Enter；页码范围为 1 至总页数。首页禁用上一页、末页禁用下一页，加载期间禁用控件，实时刷新保留页码输入草稿。
- 图片的连续浏览和“加载更多”仍使用游标窗口，不显示页码分页；内部窗口大小独立于列表的每页条数。

### 卡片、列表、弹窗

- 卡片只包围完整任务或数据区；卡片内表单和折叠项优先使用留白、字号与对齐分组，不重复叠加外框和分割线。保留主导航、表格表头、任务卡片与浮层的必要边界。
- 列表选中、悬停与禁用状态一致；长名称允许换行或省略，并能查看完整内容。空状态说明当前没有什么及下一步操作。
- 类目列表上方提供共享 Input 搜索框，按类目名称即时子串匹配、忽略大小写并统一全角字符；只更新类目列表，保留当前类目、标签编辑草稿和输入焦点。无匹配显示空状态，清空恢复列表；移动布局中搜索仍可见。
- 固定标签选择复用共享 Command / Popover 输入匹配文本、ID、类目；点击候选或方向键选择后回车直接加入列表，不显示额外添加按钮。输入过程不修改配置，选中后清空输入并更新候选与计数，已有固定标签自动排除，正负向分别匹配；中文输入法确认文字时不触发添加。列表顺序与拖拽仍保留，加入后由配置保存按钮统一持久化。
- 任务条目默认折叠，收起时展示状态图标及右侧的任务 ID，时间图标靠右对齐；长 ID 省略并提供完整提示，完整摘要通过悬浮提示或键盘聚焦查看。展开显示状态、时间、后端、种子、任务 ID、完整正负提示词、错误及取消操作。每页 15 条，通过底部上一页/下一页图标和页码输入跳转；实时刷新保留当前页与已展开条目，翻页失败保留原列表并允许重试，加载期间禁用分页操作。
- 喜欢导航只展示图标与名称，不附带数量。参数帮助统一使用 HelpTip，保持问号图标与点击区域的尺寸一致。
- 弹窗有标题、关闭入口、明确主操作；内容过长时内部滚动，操作区仍可触达。使用官方 Dialog 的 Escape 关闭、焦点圈定与返回焦点机制。
- 图片预览保持原比例，工具与状态不要遮住关键画面；加载、无图、已清理与读取失败分别显示。
- 漫游图片底栏不展示图片序号、总数、生成时间或键盘提示图标。左箭头、喜欢、右箭头按顺序居中，下载图片和图片信息入口靠右，下载在信息左侧，保存当前原图；种子与正负提示词收进官方 Popover，保留复制和下载操作，切换页面时关闭浮层。反馈只有喜欢与撤回喜欢，不提供负向评价或对应快捷键。
- 漫游恢复上次观看的图片，与喜欢页分别维护位置；初始化与清理后的列表未载入时显示加载，不选最新图或清空观看位置。按当前图片获取连续窗口，左右切图跨窗口时继续加载相邻图片，不拼接有缺口的列表。较旧边界安静停留；向右没有图片时按需生成并在「漫游」标题文字右侧显示 16px 加载图标，图片区域保持原图且不叠加加载遮罩，完成后前进一次。重复操作不重复派单；离开漫游或向左浏览取消等待界面，已提交任务可完成。失败退出加载并展示可执行的错误。
- 漫游标题右侧使用官方 Toggle 与 EyeOff / Eye 图标控制毛玻璃，默认开启，刷新恢复开启；本次页面内切图及导航保留状态。模糊从图片首次展示即生效，不使用渐变解除或悬停揭示；仅处理图片区域，工具、错误与状态保持清晰，不更改原图。
- 漫游标题右侧使用 Maximize 图标进入沉浸模式，无图时置灰。优先通过浏览器 Fullscreen API 全屏，不支持或拒绝时铺满浏览器视口；复用原图和操作控件，保持比例、不裁切，保留毛玻璃和下一张加载。底部悬浮栏仅按「上一张、喜欢、毛玻璃、下一张」排列，毛玻璃与标题开关共享状态，2 秒无操作自动隐藏；移动鼠标、点按画面或按键唤醒，悬停栏内或键盘焦点停留时保持显示。隐藏栏不可误点或聚焦，Tab 会先唤醒控件。Esc、离开漫游或离开页面均退出并清理状态，焦点返回入口；实际操作错误退出沉浸并显示原错误。沉浸中不展示图片信息、时间、计数或预取状态。

## 布局与响应式

普通漫游和沉浸模式、生成结果页与生成大图均可按空格切换对应区域的毛玻璃；漫游与生成分别维护状态，各自的页面开关、浮栏及大图保持同步。按钮提示和 `aria-keyshortcuts` 标明空格。输入、弹窗、组合键和长按重复不触发页面级快捷键，大图使用自己的按键处理，避免切换两次；切换时阻止默认滚动或误触喜欢按钮。

喜欢页复用生成结果的自适应网格与大图浏览组件，保留各自的数据和毛玻璃状态；不展示生成任务状态、清空结果或后端配置入口。点击缩略图进入大图，支持左右切换、信息及沉浸模式；网格状态下方向键不操作隐藏的漫游图片，空格切换喜欢页毛玻璃。

喜欢页取消喜欢时复用共享 AlertDialog 二次确认，说明图片将移出喜欢页并受自动清理规则影响；取消或 Esc 保留喜欢，确认后才提交反馈。等待确认期间锁定当前反馈及切图，避免重复弹窗；方向键喜欢保持幂等。

漫游与生成的图片信息面板复用同一组字段：面板标题右侧放提示词 JSON 下载；图像种子、正向提示词、负向提示词统一使用上方标题与右侧复制图标、下方内容区的布局；未知种子或使用工作流种子设置时禁用复制。内容区使用柔和背景与等宽字体，长文本独立滚动，窄屏自动换行。复制成功后原按钮短暂显示勾选图标及“已复制”无障碍标签，失败在原按钮提示，避免额外常驻状态文字；空提示词禁用复制。

所有普通栏目复用 `.workspace-content`：以喜欢页面为基准，容器最大宽度 1200px、水平居中、桌面内边距 24px，视口不大于 1024px 时为 16px。漫游与提示词不额外扩大或缩窄页面内容；提示词各子页继承同一左右边界。页面保留滚动条空间，切栏不因滚动条出现而偏移；图片沉浸模式继续全屏。

桌面侧栏统一为 144px，保留图标与短名称，不随大屏增宽；不大于 768px 时使用横向导航，主要空间留给内容。

页面按任务分区：漫游突出推荐图片与方向键操作，生成页左侧生图表单、右侧独立生成结果，提示词页管理词库与规则，设置页按后端、历史清理和数据分类。导航名称必须与内容标题相符；工具集中在各区标题附近，避免同一操作多处重复。

生成页不展示顶部操作通知，生成按钮下方也不展示最近任务状态卡；任务进度在生成结果区与任务页查看。生成按钮旁提供 outline「取消待执行任务」按钮，仅取消生成页待执行任务，使用原按钮反馈取消数量或失败原因；提交与取消相互禁用，避免同时操作。提交生图、抽取提示词和刷新规则配置在原按钮显示加载图标与结果，成功后短暂显示勾选并恢复；失败或提交结果待确认保留在按钮上，完整原因及安全重试说明通过共享 Tooltip 和可访问状态提供。提交成功只表示任务已接收，生成进度仍在结果区展示；后台同步失败保留在结果区，不转成顶部横幅。

生成页的共现候选区按两列排列「生成预设 / 抽取模式」；预设刷新图标与标题同排。固定种子和连续序列按「数值 / 生成后行为」成对排列，字段标题与控件间距统一，输入和下拉均使用默认 36px 高度；仅展示当前模式需要的参数。搜索设置保留折叠；自动抽取开关与抽取提示词按钮同排，窄屏空间不足时自然换行。不增加嵌套卡片或分割线，保留现有控件 ID、表单校验和控制器行为。

每次数量与生成次数并排使用带整数上下限的 Input，均默认 1、范围 1–10；帮助说明逐轮按槽位抽取、轮内共用提示词、生成后控制、跨轮图像种子、顺序执行与工作流多输出。生成结果采用紧凑网格，少量图片不拉成巨幅；生成与喜欢页的缩略图等比例居中填满卡片（cover），超出部分裁切，大图继续完整展示（contain）；喜欢图标悬停或 focus-within 展示，触屏常显，缩略图不附带常驻种子与工具底栏。结果标题右侧放毛玻璃及一键清空图标，毛玻璃默认开启且与大图共享状态，图片首次显示即模糊，刷新恢复开启；与漫游毛玻璃分别管理。点击图片打开官方 Dialog 大图，左右切图、↑ 喜欢、空格切换毛玻璃，下方向键不执行操作；操作栏按上一张、喜欢、下一张居中排列，毛玻璃按钮位于右上角关闭按钮左侧，图片信息靠最右，不展示图片删除和下载按钮。漫游也移除原图下载入口，信息面板保留提示词 JSON 下载。输入、辅助浮层与忙碌状态保留自身键盘行为。

生成与喜欢大图的沉浸布局与漫游一致：右上悬浮菜单放毛玻璃和退出沉浸模式，底部放上一张、喜欢、下一张；漫游右上菜单在毛玻璃前增加播放/暂停（保留时间进度环），底部另保留不喜欢。使用相同的按钮尺寸、间距和毛玻璃 Toggle 状态；Esc 先退出沉浸，再关闭浮层。切图保留隐私状态，分页等待与缓存重读期间保留画面，确实无图才关闭。清空按钮的可访问名称和提示明确区分“未喜欢删除，喜欢移出生成页”；操作失败在当前大图或结果区可见，重复操作在忙碌期间禁用。窄屏表单和网格上下排列，工具保持可触达。生成与漫游分别维护图片列表、分页和展示 DOM，跨来源的喜欢图片仍汇总到喜欢页。

### 设置

设置分类按「通用、漫游、后端、历史」排列，沿用同一内容宽度（780px）与表单节奏：字段标题行至少 24px，标题至控件 8px，同组字段 16px，分区 24px；双列在窄屏转为单列。复用 `.settings-field` 与 `.settings-stack`，避免借助 label 外边距排列整个表单。主题和漫游分段控件左对齐，单位放在 InputGroup 内；数据路径使用次级标题与等宽正文，长路径可换行。保存操作统一在表单右下，测试连接留在左侧。折叠区域保留轻量标题，不增加卡片套层或装饰分割线。

设置分类使用横向 Tabs（通用、后端、漫游、历史），保留页面标题「设置」，分类内容不重复显示标签页标题。漫游配置预取数量、生图后端和候选词库，规则及业务状态由服务端管理；漫游页面不展示预取数量、进度等常驻提示，不增加生图表单，仍保留下一张等待动画和操作错误。顶部只显示后端可用状态，不重复放置设置入口；可用表示至少一个已保存后端通过只读连接预检，读取配置和保存后检查，不新增定时探测。

漫游页右上按「播放/暂停、毛玻璃、沉浸模式、漫游选项」排列四个 32px 图标按钮，播放保留时间进度环，毛玻璃与沉浸入口直接可用；共享 Popover 仅设置展示时间，普通和沉浸底部操作栏仅保留切图与评价。菜单宽 240px、内边距 12px，展示时间标题与带“秒”单位的 InputGroup 同行；输入回车或失焦保存，不显示独立保存和播放按钮。偏好范围、漫游方式和推荐力度统一在设置 → 漫游中调整。菜单收起时不可见控件不进入 Tab 顺序，关闭和退出沉浸后焦点回到入口。设置 → 漫游同样提供自动播放间隔、偏好范围与漫游方式；两个入口共用已保存配置，局部修改不覆盖其他字段草稿。改变范围、方式、后端或候选预设时暂停自动前进和旧窗口合并，保存后按产物修订重读当前及后续窗口，再恢复播放意图；旧请求回包不得合回窗口，失败保留原选择和当前图片。空喜欢词池仅在用户等下一张时结束加载并提示，后台补图不反复弹出通知。

后端设置沿用上述统一字段节奏与默认 36px Input/Select；标题工具采用 icon-xs，不撑高单侧标题。节点参数面板使用共享 Collapsible，默认折叠，切换后端时重新折叠；点击透明的“箭头＋标题”展开，悬停与展开状态均不增加胶囊底色，保留键盘焦点环；JSON 切换、文件导入、读取默认节点参数或参数校验失败时自动展开。折叠保留草稿与表单控件，JSON 和导入操作仍在标题右侧。节点参数按节点分组，单字段占满一行，多个参数两列排列；输入绑定集中左侧，输出节点右侧，窄屏转单列。保留一层节点参数边框，不增加分割线。JSON 导入使用向下进入托盘的 Download 图标，名称仍为“导入 ComfyUI API 工作流 JSON”；它触发本地文件导入，JSON 按钮继续切换参数/源码视图。

漫游设置中的「历史图片数量上限」与预取数量并列，使用整数 Input（`0`–`100000`，默认 `0`）。HelpTip 说明关闭值、当前图片之前全部历史计数、当前与预取不计、最早优先、未喜欢删除本地图片和 JSON、喜欢只从漫游隐藏以及生成页不受影响；删除后果可通过明确的帮助按钮查看。保存后根据产物修订重读图片和观看位置，保留其他设置草稿。

| 视口 | 布局原则 |
| --- | --- |
| 大于 1024px | 桌面分栏；主要内容弹性占满可用空间 |
| 768–1024px | 收紧侧栏与间距，减少同时并列的次级区域 |
| 640–768px | 主要面板改为上下排列；导航允许横向滚动或换行 |
| 不大于 640px | 单列，表单工具与操作按钮换行；弹窗适应屏宽 |

Flex / Grid 内容列设置 `min-width: 0`，长 ID、路径和提示词适当换行。页面不出现意外水平滚动，图片不挤压表单；确实需要横向阅读的代码区独立滚动。调整断点应同时检查 Feed、编辑器与弹窗。

## 键盘与可访问性

- 所有可交互控件可用 Tab 到达；保留清楚的 `focus-visible` 焦点环，不全局移除 outline。
- 原生按钮使用 `button`；导航使用链接。图标保持统一尺寸和描边，不用表情符号充当核心操作图标。
- 图片视图方向键：左键上一张、右键下一张、上键喜欢；按钮可撤回喜欢，上键重复操作不撤回。下键不执行删除或负反馈。输入框、可编辑区域、选择控件和弹窗中不触发全局快捷键；沉浸模式仍保留这些操作，Esc 退出。
- 动态状态使用合适的状态区域；错误信息及时可见，避免每次轮询重复播报。
- 小字号与辅助信息仍需清楚可读；移动端主要操作保持足够点击面积。

## 开发与验收

1. 先复用 `web/src/components/ui`，通用行为改在组件，共享视觉改在 `theme.css`，页面文件只处理布局与业务表达。
2. 不添加覆盖组件字号、圆角、填充与焦点的未分层全局选择器；动态控件与 React 控件复用同一配方。
3. 修改源码后，在 `web/` 目录运行 `pnpm install --frozen-lockfile`、`pnpm run typecheck`、`pnpm run build`；精确构建目录与数据布局见 [前端开发](../README.md#前端开发与设计)。
4. 运行受影响的前端和接口测试，确认构建资源已同步。既有动态 DOM 的 ID、事件、草稿与保存行为必须保留。
5. 检查常规、加载、空、错误、禁用、选中、未保存状态；验证键盘焦点、长文本、窄屏与弹窗滚动。
6. 使用独立测试实例/标签页检查界面，不覆盖用户当前草稿；说明实际验证范围，模拟接口通过不代表真实 GPU 出图通过。

后续新增页面遵守此文档；新增全局规则只在此维护，源码中的 token 和组件实现是具体值与行为的依据。

前端只有 `web/index.html → web/src/main.tsx` 一个入口，提示词编辑器作为工作台内的 `#prompts` 视图。切换视图保留草稿，不使用 iframe 或新标签页承载应用功能；后端只提供 API、事件和静态产物。

提示词预设切换、删除和重新加载需保护未保存草稿；保存按钮只在有变动且内容有效时启用。词库分页加载，不挂载全库控件。生成参数通过帮助提示解释PMI 含义、最低共现次数、数量包含固定词和变化预算按增删计数，预览显示真实停止原因与序列信息。

预览提示词按完整词项保持逗号分隔，悬停、键盘聚焦或触屏点按可查看与当前组合其他词的 PMI 和共现次数；同一查询同时高亮正负两侧词项。复用 shadcn Tooltip，锚点强调、正关联使用 success 浅底、负关联使用 warning 浅底、未保留关系使用 destructive 浅底与点线、未知词使用弱化文字与点线；浮层给出明确数值或无统计状态，不将负 PMI 命名为冲突。

网站侧栏“设置”入口使用 Lucide Settings 齿轮图标；漫游选项继续使用 Settings2 调节图标，以区分全局设置与当前页面选项。

桌面与主屏幕应用的外壳固定在视口内，主文档不滚动；顶栏和导航始终可见。各栏目内容使用独立滚动容器，切换栏目保留各自的滚动位置；标题位于滚动区上方。手机（≤640px）复用原导航控件呈现底部五栏，桌面保持侧栏；平板窄屏仍可横向导航。导航与顶栏不随栏目内容滚动。弹窗、下拉菜单与沉浸模式保持各自的滚动和全屏行为。

喜欢页标签筛选放在网格上方，复用 Popover/Command 多选列表与紧凑已选项，提供搜索、单项移除、清空和图标排序；列表右侧显示对应喜欢图片数量，默认字典序，数量排序按降序、同数按字典序。筛选列表与图片保持独立滚动，具体行为和接口见 [标签筛选](liked-tag-filter.md)。

设置中的历史页承载任务记录与图片清理，图片清理使用默认折叠的共享 Collapsible，任务记录保留每页 15 条的统一分页与详情。通用页在主题下展示数据位置；侧栏不提供独立任务入口。各表单保持挂载，切换分区和折叠不丢草稿。

## 移动端与触屏

- 手机底部五栏固定展示漫游、生成、喜欢、提示词和设置，保留底部安全区；导航行 48px，顶栏内容行 44px，横屏顶栏 40px，安全区额外计入。桌面及主屏幕应用使用 `100dvh` 固定外壳与栏目内部滚动。普通 iPhone WebKit 浏览器使用真实文档滚动：外壳自然排布、顶栏 sticky、底栏 fixed，内容底部预留导航高度；切换栏目保存和恢复文档滚动位置，弹窗及沉浸期间锁定文档。地址栏收起需要浏览器响应用户滚动及足够的内容高度，短页不保证收起，不通过空白占位或程序滚动模拟隐藏。
- 手机漫游图片与工具栏使用两行 Grid；图片绝对定位于明确的图片区域中，避免百分比图片高度撑大容器。主屏幕模式填满剩余可用高度，普通浏览器使用 2:3 图片框且不超过 72svh；大图保持 contain。图片卡片统一圆角裁切及轻边框，模糊不外溢，工具栏不覆盖普通图片区域；沉浸工具栏保持悬浮。
- 窄屏或触屏设备的主要控件点击区域至少 44×44px，保留 Luma 图标大小、圆角和配色。文本/数值输入使用 16px，减少手机聚焦后的自动放大，不禁止页面缩放。
- 手机表单、固定正负词与预览采用单栏；图片网格保留两列，缩略图喜欢操作直接可见。选择菜单受视口高度限制，可滚动且不会横向挤出屏幕；漫游选项内容在空间不足时换行。
- 漫游、生成和喜欢大图支持单指左滑下一张、右滑上一张，仅图片区域接收手势；竖向起势、多指缩放、控件点击不切图。键盘行为与各自的较旧/较新分页规则保留，滑动本身不产生喜好反馈。
- 沉浸模式在桌面和触屏均显示右上角悬浮菜单，避开顶部与右侧安全区；与底部操作栏一起唤醒、闲置约 2 秒后隐藏，鼠标悬停或键盘聚焦任一栏时保持显示。隐藏控件同时退出焦点与无障碍顺序，退出后焦点返回原入口。触摸不作为鼠标悬停，帮助仍可点按查看。
- 图片信息和预览共用复制帮助方法，优先 Clipboard API；局域网普通 HTTP 下回退浏览器复制命令。浏览器拒绝时保留按钮错误反馈与可选择文本。

## 主屏幕应用

- `web/public/manifest.webmanifest` 定义安装身份、名称、根路径范围及 `/#feed` 启动入口；通过既有 `/static/ui/` 提供，不新增后端 API。清单位于静态目录，但启动路径和 scope 必须指向应用根路径，避免安装后打开静态文件目录。
- `web/index.html` 提供清单、iOS standalone 元信息与 `apple-touch-icon`。`web/public/icons/` 的 180 / 192 / 512 PNG 沿用 `data/designs/pictide-icon-v1.png` 品牌稿导出，实际运行资产提交 Git；图标有不透明底色，由系统裁切。
- `display-mode: standalone` 恢复固定外壳与栏目内部滚动，不使用普通浏览器的文档滚动布局；顶部/底部继续使用现有安全区。主题渲染同时更新 `theme-color`，与显式黑白或跟随系统保持一致。
- 本版不注册 Service Worker，不缓存 API、图片或旧构建；主屏幕模式仍在线连接 Pictide。不能将独立窗口或安装元信息称作已支持离线生图。
