# 图片评分缓存生命周期

原来的手动清理方案已撤回。用户不需要维护已删除图片的评分缓存。

## 架构和职责

移除设置页清除缓存按钮、对应通知文案、HTTP 接口和 Application / Store 的手动清理方法。

在 Store 内部复用一个图片删除方法：在原有事务里标记图片已删除、删除对应评分缓存、登记图片文件删除队列。生成页清理、过期清理和漫游历史裁剪均使用它。仅隐藏但仍保留的图片继续保留评分。

Repository 初始化时清理旧版本留下的已删除图片评分，重复执行安全，不增加迁移标记或后台任务。保留评分写入前的图片状态检查，防止晚到结果重新写入。

## 数据保护与验证

- 只清理 `artifact_preference_scores`；任务、反馈、学习证据、模型参数和标签向量保留，不执行 `VACUUM`。
- 临时数据库覆盖三条删除路径、仅隐藏的图片、事务回滚、晚到写入和重复启动兼容清理。
- 设置布局恢复六行；继续验证漫游列表失效后自动播放正常。

实现验证：49 项相关后端测试、7 项浏览器测试通过，前端类型检查和生产构建通过。测试使用临时数据，覆盖普通／沉浸漫游及桌面／手机设置布局。
