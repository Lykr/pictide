# 前端页面设计一致性修订

日期：2026-11-06。审查基线：`aa5b775`。依据修订后的[设计系统](../../../dev/design-system.md)，核对五个主页面、六类设置，以及图片大图、恢复、通知和引导等共享界面。

## 设计判断

保留 Neutral / Luma 的克制视觉：图片是主角，工具使用统一的圆角、柔和底色和紧凑层级。优先消除语义、对齐和状态反馈的差异，不增加新的页面区域。

## 实际修订

| 项目 | 修订与理由 |
| --- | --- |
| 喜欢状态 | 漫游、画轴、缩略图和大图统一使用共享粉色主题；删除和错误保留独立语义。画轴标记跟随图片，毛玻璃不影响标记。 |
| 表单层级 | 提示词编排、预览与其他表单统一标签字重和 8px 间距；标签关联实际输入或选择控件，点击即可操作。 |
| 标签输入 | 新词输入与区域左侧对齐；拖动手柄的占位只留给已有词项，释放手机输入宽度。 |
| 保存与等待 | 显式保存统一图标与等待反馈，保留按钮文字和尺寸；读取模型、预览或删除不会被显示成正在保存。 |
| 连接测试 | 等待留在测试按钮，结果使用共享通知；测试中修改参数后提示重新测试，避免旧结果被误认为当前配置的结果。 |
| 图片工具 | 大图毛玻璃使用与列表一致的 Toggle，保留空格快捷键及开关状态；网络复制和刷新使用共享图标按钮与提示。 |
| 自适应布局 | 生成操作按标签实际宽度分配空间和换行；窄屏设置标签行保持当前项可见，不移动页面或夺取焦点。 |
| 通用设置 | 局域网和 ComfyUI 长分组的标题对齐首个控件，不再随二维码或展开表单居中下移。 |
| 文案层级 | 画幅池复用说明移入名称旁的帮助；补齐中文环境中的 OpenAI 兼容 API 名称。 |
