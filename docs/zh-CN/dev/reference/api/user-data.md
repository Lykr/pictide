# 用户数据

[English](../../../../dev/reference/api/user-data.md)

[API 索引](../../api.md) · [通用约定与错误](../../api.md#通用约定)

| 方法 | 路径 | 请求 | 响应 |
| --- | --- | --- | --- |
| GET | `/api/user-data/export` | 无 | 包含两种数据的可迁移 ZIP 附件 |
| POST | `/api/user-data/export` | `{liked_images:布尔值,preferences:布尔值}` | 所选类别的 ZIP 附件 |
| POST | `/api/user-data/import` | `Content-Type: application/zip` 的 ZIP 内容 | 导入摘要 |

两个接口都要求回环地址与本机 `Host`。应用目前没有账户认证，因此这些接口不能通过局域网地址使用。

两种导出方式都要求至少选择一个类别。图片和 `state/` 文件只在其类别被选择时存在。清单与 `data.json` 记录 `liked_images` 和 `preferences` 两个类别；没有类别信息的旧版归档按两种都包含处理。喜欢图片类别包含原图、提示词和喜欢记录；学习偏好类别包含恢复所需的最新推荐事件、当前证据、重置边界、分数范围与后验策略。

导出不包含 API 密钥、ChatGPT 令牌、未喜欢图片、预设、画幅池、通用与漫游设置、缓存、模型、词库或运行文件。它用于迁移喜欢图片和学习偏好，不替代完整数据目录备份。

导入限制为压缩后 4 GiB、展开后 8 GiB。服务器在写文件或数据库前校验路径、数量、JSON、图片元数据、推荐证据、策略矩阵及全部校验和。导入只应用归档包含的类别：仅喜欢图片不会改变当前推荐状态；仅学习偏好不会添加图片。推荐策略版本在包含学习偏好时必须一致；特征或模型版本不同时，导入模型无关的事件快照，丢弃不兼容的后验矩阵与派生证据，并使用当前本地模型重建学习状态。响应以 `preferences_migrated` 表示已立即重建，或以 `preference_rebuild_pending` 表示之后在后台继续。

应用学习偏好时会建立内部学习边界，避免当前保留的喜欢立即重新进入导入偏好；之后的新反馈仍会正常学习。策略不兼容、损坏、截断或超出限制的归档返回 `400`，不修改当前数据。

导入前会在 `backups/before-user-data-import-<时间>/pictide.sqlite3` 创建一致性数据库备份。导入添加尚不存在的喜欢图片，同 ID 图片保持不变；当前本地学习事件、证据、后验状态、重置边界、分数范围与评分缓存由导入状态替换。图片 API、工作流、预设、画幅池、通用与漫游设置以及未导入图片保持不变。

运行中的生成任务或其他正在进行的设置写入会以 `409` 阻止导入。数据库事务失败时删除本次复制的图片文件。成功响应包含导入数、跳过数、偏好证据数、备份相对路径和图片修订号。
