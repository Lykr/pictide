## 应用壳层

普通页面共用 `.workspace-content`，居中、最大宽度 1200px；桌面内边距 24px，宽度不超过 1024px 时为 16px。漫游与提示词页使用相同水平边界，预留滚动条空间以免切换时跳动。桌面侧栏宽 144px，使用短名称和图标；窄屏调整导航形式，不在大屏扩大侧栏。

桌面与主屏幕应用使用固定 `100dvh` 外壳，各栏目独立滚动。导航保持可见，保留各栏目的滚动位置，标题位于滚动内容上方。内容末端留白 16px，窄屏 8px，提示词内部区域同样适用。Flex / Grid 列使用 `min-width: 0`，长路径、ID 与提示词在自身区域内换行或滚动。

| 视口 | 布局 |
| --- | --- |
| 大于 1024px | 桌面分栏，主体弹性伸缩 |
| 768–1024px | 收紧间距，减少同时展示的次要面板 |
| 640–768px | 主面板堆叠，允许横向导航 |
| 不大于 640px | 单列表单与固定底部五栏导航 |

手机底部导航展示漫游、生成、喜欢、提示词和设置，行高 48px，另计安全区。顶部内容行 44px，横屏 40px。普通 iPhone WebKit 浏览器采用文档滚动、sticky 顶栏和固定底部导航，切换栏目保存并恢复文档滚动位置。弹窗和沉浸模式锁定文档。浏览器工具栏收起依赖真实用户滚动及内容高度，不用空白占位或程序滚动模拟。

主屏幕应用隐藏 Pictide 品牌栏，保留顶部安全区，通过各栏目标题定位。弹窗、菜单和沉浸视图保留各自的滚动行为。

## 漫游

右上工具依次为播放/暂停、毛玻璃、沉浸模式和漫游选项，使用共享 32px 控件；播放保留时间进度环。选项简要解释展示间隔、偏好范围、漫游方式和推荐力度，使用共享 Popover 与 ToggleGroup。浮层按内容定宽，普通最小宽度 320px，受视口及 Radix 可用宽度限制，外侧至少留 12px；窄屏允许整组选项换行。

展示间隔标题和带秒单位的 InputGroup 同行，回车或失焦保存。漫游设置与浮层共享已保存配置，不覆盖其他草稿。修改范围、方式、后端或当前候选预设时，暂停自动前进和旧窗口合并；保存后重读修订后的窗口，再恢复播放意图。失败保留原选择和当前图。后台预取不反复通知喜欢词池为空。

漫游独立于喜欢页恢复上次观看图片。初次或刷新窗口加载期间保留观看位置，不跳到最新图片。读取当前图周围的连续窗口，跨边界时加载相邻窗口。较旧边界安静停止；较新边界通过既有操作和事件请求生成，保留当前图，就绪后只前进一次。重复输入不重复提交。离开漫游或浏览更旧图片会取消界面等待，已提交工作可以继续完成；失败结束加载并给出有效通知。

普通漫游等待在标题旁使用 16px spinner，不用遮罩覆盖图片；沉浸加载使用下文独立指示器。

## 隐私与图片浏览

页面初始化默认开启毛玻璃，从图片首次绘制即生效，只影响图片，不影响工具、错误与进度。页内导航保留毛玻璃状态，刷新恢复保护。漫游与生成分别维护状态，各页同步工具栏和大图控件。

空格切换漫游、生成结果或大图中当前图片区域的毛玻璃，通过 Tooltip 和 `aria-keyshortcuts` 提示。忽略可编辑输入、自行处理按键的弹窗、修饰键和重复 keydown，避免意外滚动、评价或大图重复处理。

漫游、生成和喜欢的图片信息共用字段布局：偏好评分、种子、正向提示词和负向提示词。可复制字段在柔和底色的等宽正文上方放标题和右对齐复制按钮；种子不可用、提示词为空时禁用复制。长文本内部滚动，窄屏换行。提示词 JSON 下载位于面板标题旁。评分保留一位小数，区分加载、不可用和无区分度状态；原始评分及相对刻度解释放在帮助中。见[图片评分](../api/images.md#喜欢筛选与图片偏好评分)。

复制优先使用 Clipboard API，普通 LAN HTTP 回退到浏览器复制命令。复制失败仍保留可选择文本；操作结果使用[通知](components.md#悬浮通知)。

## 生成与喜欢

生成页桌面表单与独立结果区并排，窄屏堆叠。共现预设与抽取模式使用两列，预设刷新位于标题行。种子或序列值与生成后行为配对，高级搜索折叠，隐藏模式保留草稿。每次数量和生成次数均为 1–10 的整数，初始为 1；帮助解释每轮提示词、轮内共享、跨轮种子、顺序执行和工作流输出。

取消待执行只作用于生成页排队任务，与提交互斥禁用。生成进度保留在结果区和任务历史；提交成功表示任务已接受。临时结果和错误使用共享通知层。

生成与喜欢共用紧凑响应式缩略图网格和大图查看器，数据及毛玻璃状态分别维护。缩略图居中 `cover`，完整图片 `contain`。喜欢控件在悬停或聚焦时显示，触屏常显；缩略图不常驻种子或工具行。结果工具提供毛玻璃和清空，清空说明哪些未喜欢图片会删除、哪些喜欢图片仅移出生成页。

大图使用共享 Dialog，上一张、喜欢和下一张居中，信息位于左下，毛玻璃紧邻右上关闭按钮。不提供完整图片下载，信息保留提示词 JSON 下载。分页等待和缓存重读时保留画面，仅在没有图片时关闭。Escape 先退出沉浸模式，再关闭查看器。

生成/喜欢 Dialog 的外框在减去四侧安全区的视口中定宽高并居中；内部 padding 不能代替让外框避开 Home 指示条。共享 `--safe-area-*` 读取浏览器设备边距，旋转重新计算安全矩形。沉浸图片可填满视口，浮动控件仍在安全区内。

喜欢页支持最新/偏好评分排序，网格上方为可搜索的标签多选筛选，显示匹配喜欢图片数量，支持单项移除、清空及独立滚动。标签默认字典序，按数量时降序、同数按字典序。偏好评分模式在毛玻璃旁提供手动刷新，Tooltip 显示最近成功刷新时间；加载更多使用中性措辞。取消喜欢使用共享确认框。喜欢页不放生成配置或任务控件。

## 提示词

词库选择、上传与刷新共用一行管理工具，下方为全宽标签搜索。窄屏保留控件分组，限制长文件名，对只读词库分页，不一次挂载全部内容。

预览依次为控制区、结果、默认折叠报告。提示词种子与生成后行为成组，连续帧位置与行为另成组，高级搜索上限折叠。状态、种子和连续变化信息位于结果上方。正负提示词使用柔和底色及对齐的复制动作，短结果不预留固定空白。

正向词通过共享 Tooltip 支持悬停、键盘聚焦和触屏查看 PMI 及共现次数，关联高亮只作用于正向词。锚点突出，正关联用 success，负关联用 warning，未保留关系用 destructive 点线，未知词用弱化点线。展示统计数值或不可用原因；负 PMI 是关联值，不称为冲突。负向提示词保持普通文本并支持复制。

## 设置

「设置」统一标题下使用通用、漫游、生图 API、LLM API 和历史标签页。表单共用 780px 内容宽度、`.settings-field` 与 `.settings-stack`：标题行至少 24px，至控件 8px，同组字段 16px，分区 24px；双列窄屏堆叠。Input / Select 默认高 36px，单位使用 InputGroup。保存放右下，连接测试放左侧。

通用设置以对齐行展示语言、主题、切图动效、引导和数据位置。数据位置只展示路径，使用柔和底色与等宽正文，窄屏标题/值上下堆叠，长路径换行，不嵌套装饰卡片。

漫游设置包含预取、历史上限、后端、播放、偏好范围、方式和推荐力度。当前提示词预设在提示词页选择，不在设置重复。历史上限为 0–100000 整数，初始为 0；帮助说明关闭值、只统计较旧图片、不计当前/预取、最早优先、删除未喜欢本地图片与 JSON，以及喜欢图片保留但退出漫游。

生图 API 使用一个可编辑工作流选择/名称控件。节点参数使用共享 Collapsible，初始折叠，切换后端恢复折叠；标题展开保持轻量。JSON、导入、读取默认值和校验错误按需展开。折叠保留全部草稿，按节点分组；单字段全宽，多字段两列，输入绑定与输出选择在窄屏堆叠。

LLM API 独立管理具名 API Key 或 ChatGPT 连接。自然语言生图 API 展示引用这些配置的选择器及管理 LLM API 入口，Danbooru 隐藏。配置跨标签页保留草稿。ChatGPT 使用明确的浏览器登录、账号/模型选择、首次套餐说明对话框和用量链接；只有操作进度保留行内，错误与结果使用悬浮通知。

历史合并任务记录与默认折叠的图片清理，任务每页 15 条，切换标签保持表单挂载。侧栏无独立任务入口。顶部可用状态来自读取/保存配置时对已保存后端的只读预检，不定时探测。全局设置使用 Lucide Settings，漫游选项使用 Settings2。

## 沉浸视图与锚点

优先 Fullscreen API，回退为浏览器视口全屏。复用当前图片与控件，保留比例、毛玻璃和加载状态。右上菜单包含毛玻璃与退出，漫游另有带进度环的播放/暂停；底部紧凑工具栏包含切图、反馈，以及适用的信息和漫游锚点。

闲置约两秒隐藏控件，鼠标移动或短触摸点按唤醒，悬停或键盘聚焦保持可见。方向键和空格立即隐藏工具，导航或聚焦变化不重新唤醒。隐藏控件退出指针、Tab 和无障碍交互，Tab 首先唤醒工具栏。滑动、多指或取消手势不唤醒。Escape、离开漫游或页面时清理沉浸状态并返回入口焦点；错误留在共享通知层，视图保留。

普通漫游锚点在同一图片卡片内展开。桌面左图右编辑区，分隔线可拖动并本机保存比例，支持方向键和 Home / End；展开/收起保持图片及卡片高度，拖动只改比例。手机编辑区位于图片下方，默认 112px 且不超过 25dvh，添加时 156px 且不超过 32dvh。输入复用预设固定词的词库搜索和 Command/Popover，排除已有锚点与预设词。点击或方向键选择词库标签，直接回车添加完整输入，输入法确认不提交。候选保留在全屏内，受可用视口限制独立滚动；Escape 先关候选，再关锚点面板。添加后收起输入。词项独立滚动，手机隐藏重复标题、数量和帮助，锁图标标识固定词。

沉浸信息与锚点共用等宽浮层，居中位于底部工具栏上方，打开向上展开，关闭向下收拢，并同步透明度。图片保持全屏，普通与沉浸共用草稿和保存行为，切图保留编辑，展开时工具保持可见。打开沉浸锚点替换信息面板，关闭返回入口焦点；Escape 先关闭面板。编辑输入和触摸不触发图片快捷键或手势。行为见[锚点指南](../../../guides/roam.md#锚点)。

沉浸加载环位于左上，不依赖菜单显隐。漫游覆盖等待下一张和图片读取，生成/喜欢覆盖图片及分页读取；成功或失败结束提示，遵从减少动态效果设置。

## 键盘与触屏

所有控件均可通过键盘到达，保留可见 `focus-visible` 焦点环。图片容器可程序化聚焦以接收快捷键，不显示外层选中边框；内部按钮、输入和分隔线保留焦点提示。

左/右切图；漫游上/下在不喜欢 ↔ 未评价 ↔ 喜欢间逐级调整，到两端停止，忽略按键重复。按钮直接选中或撤回对应评价。生成/喜欢大图上键喜欢，下键不分配操作。输入、可编辑区域、选择器和弹窗自行处理按键。

图片区单指横滑切图，不改变评价；纵向起手、缩放和点击控件不切图。主屏幕漫游上/下滑沿用逐级评价，普通浏览器保留纵向滚动。漫游键盘和主屏幕滑动评价成功后，在普通与沉浸图片水平居中、约 68% 高度显示图标与短文字约 900ms，包含撤回；与右上通知分离，不拦截触摸或唤醒控件。失败使用错误通知，不展示成功提示。切图清除提示，减少动态效果时保留静态消息。

手机图片框使用两行 Grid，图片绝对定位于明确有界的图片区。单弹性列、左右对称安全边距、居中 `contain`、圆角裁切和轻边框。主屏幕漫游填满剩余高度，普通浏览器使用不超过 72svh 的 2:3 框。普通模式工具栏位于图片区外，两侧对称弹性列，信息与锚点不挤偏中间切图控件。窄屏/触屏目标至少 44×44px，文本与数字输入用 16px，减少聚焦缩放但保留用户缩放；手机网格保持两列缩略图。

## 主屏幕元数据与本地化

`web/public/manifest.webmanifest` 定义身份、根作用域和 `/#feed` 启动地址，经 `/static/ui/` 提供；`web/index.html` 引入 manifest、iOS 主屏幕元数据及触摸图标。随包 180 / 192 / 512 图标共用官方 P 轮廓和不透明背景。作用域与启动地址保持应用根目录，主题变化更新 `theme-color`。当前不注册 Service Worker，仍连接运行中的 Pictide 服务。

React 视图和功能动作共用 `web/src/i18n/index.mjs` 的 `t` / `tr`。简体中文原文作为键，英文按领域放在 `messages/en/`；具名或位置占位符允许调整词序。默认跟随浏览器，不支持的语言使用英文，手动选择优先。用户内容、实际提示词、标签和模型/工作流技术标识保持原文。日期与数字使用所选 locale，切换语言保留值和页面状态。

切图可使用共享约 180ms 透明度过渡，初次图片、同图评价和普通重绘不触发。工具栏和毛玻璃不受影响；遵从通用设置与减少动态效果，快速导航取消前一次过渡。
