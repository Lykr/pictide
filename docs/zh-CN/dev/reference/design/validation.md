# UI 开发与验证

[English](../../../../dev/reference/design/validation.md)

[UI 设计规范](../../design-system.md) · [开发流程](../../development.md) · [针对性检查](../../testing.md)

1. 修改共享交互前，列出全部使用位置及有意差异。图片控件包括漫游、生成、喜欢、普通/沉浸和手机视图。复用 `web/src/components/ui/` 与[共享功能布局](components.md)，在所属样式文件中修改共用视觉，不叠加页面专用覆盖。
2. 保留语义目标、明确动作、草稿与保存行为。尺寸、圆角、填充和焦点规则留在共享层。
3. 在 `web/` 安装锁定依赖，运行 `pnpm run typecheck` 并构建；有运行实例时使用隔离输出目录，遵循[部署步骤](../../development.md#集成与部署)。
4. 运行相关的小组 UI、接口或浏览器冒烟，在独立实例和标签页检查受影响交互，记录使用模拟后端还是真实生成。
5. 检查常规、加载、空、错误、禁用、选中和未保存状态，包括键盘焦点、长文本、窄屏、弹窗滚动及翻译文案。
6. 保护用户草稿和数据，完成后关闭自己的验证实例与标签页。

## 布局回归基线

`web/tests/browser/layout.spec.mjs` 在桌面、手机和宽屏上检查真实应用，覆盖浅色/深色及中英文文案，断言导航居中、信息按钮位置、面板不越界、沉浸面板等宽同底色、焦点返回、减少动态效果、设置控件对齐及长路径换行。独立场景注入非零安全区 token，检查生成/喜欢 Dialog 在横竖屏旋转和进出沉浸时的外框；仅桌面手机模拟不会产生 iOS 设备边距。通过模拟生成覆盖漫游、喜欢和生成。

几何与计算样式断言是可移植基线，不依赖操作系统字体栅格化截图。每次运行另附锚点、信息和设置截图供视觉检查；共享布局变化后必须检查对应截图，几何通过不代表视觉质量已确认。现有通知检查另外保护结果/错误期间的布局、滚动与草稿。

隔离构建后运行 `pnpm --dir web exec playwright test tests/browser/layout.spec.mjs`。标准 browser 组在发行验证中包含该基线；只有有意设计变更才修改断言，接受新行为前检查全部使用位置。

布局由 React 功能组件及其样式负责，功能模型和动作通过明确订阅及回调提供数据。不用属性拦截、隐藏代理输入或 DOM 观察器同步业务状态。浏览器适配层可经 refs 测量、聚焦、管理全屏和定位浮层。

前端唯一入口是 `web/index.html → web/src/main.tsx`，提示词是同一应用的 `#prompts` 视图。导航保留草稿与各栏目位置，HTTP 提供 API、事件和构建产物。

预设切换、删除和重新读取保护未保存编辑，只有有效变更才启用保存。词库分页加载；帮助解释 PMI、最低共现、固定词计入总数及增删预算，预览展示实际停止原因和序列信息。

控件和通知见[组件规范](components.md)，外壳、响应式、图片面板、设置、键盘与触屏验收见[布局规范](layout.md)。精确 token 和组件行为留在源码，每项共享规则在所属参考页维护。

## 局域网与主屏幕兼容

浏览器请求与配置 ID 统一使用 `shared/request-id.mjs`。LAN HTTP 和部分主屏幕环境没有 `crypto.randomUUID`，此时用 `crypto.getRandomValues` 构造 UUID v4。结果不确定的操作重试沿用原 ID。主屏幕浏览器冒烟移除 `randomUUID`，检查 API 创建、生成/重试和偏好重置；这是能力模拟，不是 iOS 真机验证。
