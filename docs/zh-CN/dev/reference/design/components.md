## 按钮

| 变体 | 用途 |
| --- | --- |
| `default` | 主要提交：生成或保存 |
| `secondary` | 次级动作，如提示词预览 |
| `outline` | 导入、导出、连接测试等工具 |
| `ghost` | 导航、关闭及低强调工具 |
| `destructive` | 明确删除或不可逆动作 |
| `link` | 帮助与文档 |

每个操作区通常只放一个主按钮，保存、生成和确认保留短文字。复制、刷新、关闭、排序、下载及切图使用 Lucide 图标，导航图标旁保留名称。加载展示当前动作并阻止重复提交。

React 图标按钮使用 `web/src/components/actions.tsx` 的 `IconButton`，通常为 `ghost` / `icon-sm`，提供本地化可访问名称和 Tooltip。状态变化同步名称与提示，保留图标。

## 文案与按需帮助

页面展示任务标题、标签、值、短状态与必要动作，技术解释和长背景留在主题文档。Tooltip 用一两句话解释所属控件；字段帮助、匹配规则、来源、排序和保存说明放在对应控件。空状态提供简短解释和下一步操作。

复用 `HelpTip` 或 `data-tooltip`，不在每个输入下常驻说明段落。React 控件使用 Radix Tooltip，悬停或键盘聚焦显示；帮助图标另支持点击、Enter / Space，Escape 关闭。帮助层为 1200，高于图片信息层 1100，按需挂载在当前弹窗内。删除范围与后果仍通过明确控件或确认可查。

不变的页面状态、未保存标记和当前进度留在控件旁，临时结果与详细错误使用通知。

## 悬浮通知

全部错误、校验失败、保存冲突与临时结果共用 `components/notifications.tsx`。React 视图和功能动作调用 `shared/notifications.mjs`，状态驱动错误使用 `useErrorNotice()`。

通知位于视口右上，遵从安全区、主题和语言，保留布局、滚动、草稿与输入焦点。最多展示三条，同来源重复消息合并。Radix Toast 提供关闭、滑动移除、F8 聚焦及经原业务动作执行的可选重试。

更新检查结果（已是最新、有新版本或手动更新指引）仅在用户主动检查后进入相同通知层；读取缓存或接收后台状态事件不重复通知。当前版本、可用更新动作和下载/安装进度留在控件旁。

成功和信息通知默认 4.5 秒，错误和警告 10 秒；悬停、键盘聚焦和窗口失焦暂停计时。挂载到当前弹窗或沉浸容器，支持时使用原生 top layer，否则固定定位。在全屏和弹窗中仍可操作，错误保留沉浸模式。

加载进度、未保存标记、空状态、图片不可用占位及历史任务错误详情属于页面内容。漫游键盘与主屏幕滑动评价在图片上保留短暂图标/文字确认，沉浸时也一样；评价失败使用错误通知。其他结果统一通知，不插入横幅或改变按钮文字。

## 表单与编辑

通用设置、应用更新和数据位置使用 `components/settings-row.tsx`。所属样式负责标签/控件列、间距、手机堆叠与分组分隔；调用方提供标签与控件，宽控件用 `stackOnMobile`，新分组用 `separated`。状态及保存动作留在所属功能组件。

标签位于控件上方，通过 `label` / `htmlFor` 关联，帮助紧邻标签，placeholder 示例不代替名称。紧凑组内间距 8–12px，分区间 16–24px，帮助图标为 `ghost` / `icon-xs`。保留字段约束、无效状态及必要聚焦，包括原生校验在内的详细错误使用共享通知；前端限制补充服务端校验。

预设编排将固定正向词与共现扩展成组，负向词放在独立、初始折叠的共享 Collapsible，与同一预设保存。负向词影响生成并排除同名扩展词，不参与 PMI；隐藏与折叠保留草稿。

工作流选择与名称使用同一个可编辑 Command / Popover combobox。重命名保留选中 ID，选择自定义项提供默认名称。已保存 API Key 用固定掩码，清空后保存即移除密钥，不向浏览器返回真实密钥。

工作流节点参数只有一个面板，JSON 模式在同面板替换参数控件并共享草稿；导入替换同一草稿并更新有效绑定。无效 JSON 保持可编辑，直到修正。JSON 与导入按钮位于面板标题旁。

随机或连续模式只展示所需字段，保留隐藏草稿与共享控件。固定词输入支持共享词库搜索、完整自由文本、键盘选择与回车，不额外添加按钮。候选排除已有词，正负方向分别匹配，保留输入法组合态。保留拖动排序和移动控件，保存完整预设。

## 分页与列表

词库、任务与偏好列表使用 `components/page-controls.tsx`，通常每页 15 条。上一页、页码输入、总页数、跳转和下一页居中放在列表下方，复用 32px Button / Input。回车或跳转接受范围内整数，不可用方向和加载控件禁用；实时刷新保留页码草稿。

连续图片浏览与加载更多使用游标窗口，不使用数字页码，其内部窗口大小独立于列表页大小。

卡片组织完整任务或数据区域，内部通过间距和对齐分组，不反复嵌套边框。长名称换行或截断时仍可查看全文。词库搜索保留查询、分页与焦点。任务初始折叠，展示状态、ID 和时间；展开含后端、种子、提示词、时间戳、错误与取消。刷新保留展开项及当前页，分页失败保留列表供重试。

弹窗有标题、关闭和明确主动作，长内容内部滚动，动作保持可触达。保留 Radix Dialog 的 Escape、焦点约束和返回焦点行为。喜欢导航显示名称与图标，不显示数量。

## 图片控件

漫游与生成/喜欢大图使用 `components/image-toolbar.tsx`。信息、切图/反馈及可选尾部动作各占语义插槽；`styles/image-toolbar.css` 负责位置、触控尺寸和沉浸工具栏底色。页面样式可定位卡片内的工具栏，不重定义其插槽、内边距或沉浸外观。

全部大图信息与沉浸锚点使用 `ImageToolbarPopover`。沉浸时以整个工具栏定位，面板居中位于上方，共享宽度、底色和开合动效。生成、喜欢和漫游沉浸均可查看信息；普通漫游锚点保留桌面分栏与手机紧凑布局。

大图保留比例，工具避开重要内容，区分加载、缺失、已清理和失败状态。信息放左下，漫游锚点放右下，切图/反馈按整个图片框居中。信息含偏好评分、种子、正负提示词、复制和提示词 JSON 下载。漫游底部工具栏不放图片计数、时间戳或快捷键提示图标。

漫游支持喜欢、不喜欢与撤回，生成和喜欢大图支持喜欢。各页拥有图片列表与隐私状态。切图、毛玻璃、沉浸浮层、锚点和触屏行为见[布局与交互](layout.md)。
