# Pictide 项目协作约定

[English](../../AGENTS.md)

适用于整个仓库，以英文原文为准。

## 核心原则

- 除非明确指定，使用系统当前语言。
- 先说结果和判断，只保留有助理解、决策或行动的信息，避免防御性假设、自我辩解、免责套话和重复汇报。
- 优先服务图片漫游体验。当前处于概念验证阶段，选择最小完整方案，复用现有机制，避免推测性复杂设计。
- 保护用户数据、无关修改与已有历史。开发和验证与用户正在运行的应用隔离。
- 尊重既定职责和模块边界，自主完成已批准的工作；边界变更按开发流程确认。
- 按影响范围验证，准确报告证据与限制，区分已实现、已部署、已发布和未验证。
- 每项规则只在所属文档维护，行为变化时同步更新；本文件只保留原则与路由。
