# 提示词与预设

[English](../../guides/prompts.md)

[文档导航](../index.md)

在这里保存喜欢的题材和风格，让 Pictide 按预设帮你补充提示词。直接用默认预设也能开始，之后再慢慢调整。

## 词库与预设

词库提供可组合的标签，预设保存你的固定词与组合方式。

在「编排」选择预设，加入希望保留的正向词；需要避开的内容可填入负向提示词。固定词支持词库标签和自己的完整描述。新用户的默认正向词是 `general`，可以移除或替换。使用 OpenAI Images 或 Gemini 时，负向提示词需要留空。

点击「预览」先看看会组合出什么，只生成提示词，不生成图片。满意后保存：选择的预设会用于漫游和生成，编辑内容保存后才生效。生成页已经填写的提示词会保留，再次按预设生成提示词时使用新选择。

预设名称可直接修改；也可以复制一份，为不同题材分别保存。

## 调整组合

先试默认参数，需要时再调整：

- **数量上下限**：控制提示词长度，包含固定正向词。
- **PMI 阈值与最低共现次数**：控制标签之间的统计关联要求。门槛越高，能补充的词通常越少，结果可能短于目标长度。
- **连续变化预算**：控制顺流与连续预览的变化幅度，`0` 保持原组合。

统计关联可帮助组合标签，实际画面仍由生图模型决定。

## 添加与切换词库

便携包默认随带 `filtered`，无需自行准备。需要更广的标签范围时，前往[词库版本](vocabularies.md)下载 `all-ratings`。

在「提示词 → 词库 → 上传」中选择下载的 `.sqlite3` 文件，成功后自动选用。也可将成品放进数据目录的 `libraries/`，刷新后选择。多个版本可以并存，切换会保留个人预设和固定词，新生成的提示词使用新词库。

## 数据准备

想从原始数据制作自己的词库，见开发文档中的[数据处理](../dev/corpus.md)。日常使用直接下载成品即可。
