# 设置与清理

[English](../../guides/settings.md)

[文档导航](../index.md)

在「设置」中调整显示习惯、查看生图任务，并管理图片占用的空间。

## 通用设置

界面语言和主题可以跟随系统，也可以自行选择；图片切换动效也能在这里关闭。设置会自动保存，数据目录的路径也在这里查看。

想再走一遍接入服务和漫游的简短引导，在「新手引导」一栏点击「开始引导」即可。

点击「检查更新」查找新的稳定版本。检查、下载和安装均由你手动触发，Pictide 不会自动更新。兼容的便携版本可选择「下载更新」，完成后「安装并重启」。请先保存编辑并等待生图任务结束；图片、偏好、模型和所选数据目录会保留。

无法直接安装时，可打开发行说明手动更新；源码部署始终手动更新。命令行用法见 [Windows](setup/windows.md#更新)、[macOS](setup/macos.md#更新)、[Linux](setup/linux.md#更新)。

漫游节奏见[漫游指南](roam.md)，连接生图服务见[快速开始](getting-started.md)。

在「LLM API」中管理具名文本服务连接，支持 API Key 或 ChatGPT 登录；在「生图 API」中选择 Danbooru 或自然语言提示词类型，自然语言模式使用已保存的 LLM API。详见[接入说明](getting-started.md#自然语言提示词)。

## 本地 ComfyUI 启停

在「通用」中开启「跟随 Pictide 启动和退出」，选择已保存的本机 ComfyUI 生图 API，再点击「自动识别」或填写安装目录。在「高级启动配置」中检查 Python 和启动参数，点击「保存启停设置」。修改在下次启动 Pictide 时生效。

ComfyUI 已运行时直接复用，否则按配置启动并等待就绪。退出 Pictide 只会关闭由它启动的进程；关闭浏览器不会退出 Pictide 或其服务。启动失败时，设置中会保留错误和日志位置，便于修正配置。

等待 ComfyUI 启动时，终端显示动态等待条、已用时间和最近的启动输出，并保留日志路径。服务就绪后结束等待显示。

请在运行 Pictide 的电脑上通过 localhost 地址配置。远程生图服务沿用原有启停方式；由 Pictide 安装的 Windows 环境默认继续自动启动，除非手动关闭此设置。

## 任务记录

在「历史」中查看生图进度和失败原因，取消不再需要的任务。生成页也可以一次取消尚未开始的生成任务，已在生图服务中运行的任务会继续执行。

## 历史图片清理

「历史 → 图片清理」控制未喜欢图片的保留天数，默认 **1 天（24 小时）**，设为 `0` 可关闭过期清理。喜欢的图片不参与自动清理。

过期图片会在使用应用时清理，本地图片及其提示词一并删除，无法恢复。撤回喜欢后，图片重新按原来的生成时间计算保留期限，可能很快被清理。

需要长期保留整套数据时，先做[备份](backup.md#备份与恢复)。
