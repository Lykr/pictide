# 局域网与主屏幕应用

[English](../../guides/access.md)

[用户文档](../index.md)

让手机、平板或另一台电脑访问同一个 Pictide，继续浏览和漫游。

## 局域网访问

1. 电脑与手机连接同一个可信局域网。
2. 在运行 Pictide 的电脑上，通过 localhost 地址打开「设置 → 通用」，开启「局域网访问」，本次运行立即生效。
3. 手机扫描显示的二维码，或复制局域网地址。有多个地址时，选择手机所在网络的地址。

切换时本机网页会保持连接。关闭局域网访问会拒绝局域网请求，并断开已连接的远程事件流。希望启动时直接开放，可使用 [Windows](setup/windows.md#局域网访问)、[Linux](setup/linux.md#局域网访问)、[macOS](setup/macos.md#局域网访问) 对应的启动参数。

Docker 用户见 [Docker 手机访问](setup/docker.md#手机访问)，手机使用宿主机映射后的地址和端口。

电脑上的 Pictide 需要保持运行；电脑 IP 变化后使用新地址。无需开放 ComfyUI 端口。

所有访问设备共用图片、设置和偏好，也都能生成和删除图片。请只向可信局域网开放，无需配置路由器端口转发。

## iPhone 主屏幕应用

用 Safari 打开局域网地址，依次选择「分享 → 添加到主屏幕 → 添加」；若出现「作为 Web App 打开」，保持开启。之后点击主屏幕图标，就能在独立窗口使用 Pictide。

主屏幕应用仍需要连接正在运行 Pictide 的电脑。电脑 IP 改变后，用新地址重新添加。

界面更新后，在 iOS 多任务切换器中彻底关闭 Pictide，再从主屏幕打开即可。普通更新无需重装；若需更新安装时的图标或窗口模式，再移除旧快捷方式并重新添加。
