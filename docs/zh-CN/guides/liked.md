# 喜欢

[English](../../guides/liked.md)

[文档导航](../index.md) · [漫游](roam.md) / [生成](generate.md)

「喜欢」收集你在漫游和生成中留下的心动图片，方便回看、寻找灵感，也让 Pictide 逐渐了解你的喜好。

## 浏览与管理喜欢

点击图片看大图，浏览方式见[图片浏览](images.md)。不再喜欢的图片可以撤回喜欢。

已喜欢的图片会保留，即使清空[生成结果](generate.md#清空生成结果)也不会删除它们。

## 偏好评分排序

想找回最近收藏的图片，选「最新优先」；想先看更贴近当前口味的图片，选「偏好评分」。积累新反馈后，手动刷新评分即可更新排序。

## 标签筛选

搜索并选择标签，缩小收藏范围。选择多个标签时，只显示同时包含这些标签的图片。
