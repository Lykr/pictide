# 认识 Pictide

[English](../../guides/about.md)

[用户文档](../index.md#用户文档) · [开始使用](getting-started.md)

**随你漫游，新的画面徐徐展开。**

即使还说不清想看什么，也可以开始漫游。Pictide 让图片随着你的探索不断生成，无需先手写提示词或确定创作目标。浏览、表达喜好，也可以随时引导接下来的方向。

## 发现、引导、收藏

- **发现新画面**：进入[漫游](roam.md)开始浏览，用喜欢和不喜欢帮助后续推荐逐渐贴近你的偏好。
- **留住喜欢的元素**：用锚点保留人物、颜色或场景，让探索围绕感兴趣的方向继续。
- **回看偶然遇到的好图**：在[喜欢](liked.md)中收藏和查找图片。有明确想法时，也可以到[生成](generate.md)主动生图。

默认预设就能开始。想固定一种风格或调整画面组合时，再打开[提示词与预设](prompts.md)。

## 本地与个人

图片和偏好保存在你的电脑上。生图能力由你连接的 ComfyUI、OpenAI Images 或 Gemini 提供，准备步骤见[安装与接入](getting-started.md)。

## 产品边界

Pictide 专注图片漫游：发现画面、引导变化、收藏回看。生成、预设和设置都围绕这段体验展开，默认值应足够让人轻松开始。

节点工作流编辑和生图模型管理交给所连接的后端；复杂修图、合成与生产流水线交给相应创作工具。模型市场、通用环境管理和专业制作属于当前产品重点之外。

## 体验目标

轻松看到第一张图，等待清晰可预期，浏览时保有新鲜感，想引导时能自然地控制方向，喜欢的画面也容易再次找到。新功能优先服务于这些体验。

反馈会逐渐影响推荐，不保证下一张就符合心意；锚点提供更直接的方向引导。当前推荐如何学习，见[推荐架构](../dev/architecture/recommendation.md)。
