# 提示词与共现预设

[文档导航](../README.md) · [候选接口](../reference/api/candidate.md)

先在「词库」查找标签，在「编排」保存固定词与共现参数，再到「预览」检查结果。

## 词库与预设

词库来自离线导入，支持查看和选取，不提供新增、删除、启停标签或手动修改分类。固定正向词作为生成锚点，固定负向词独立输出；它们及生成参数保存在可编辑预设中。已有任务保存提交时的文本，编辑预设不会改写历史。

## 添加与切换词库

在「提示词 → 词库」点击上传按钮，选择已处理的 `.sqlite3` 或 `.sqlite3.gz` 文件，成功后自动选用。

也可以把 `.sqlite3` 文件放进当前数据目录的 `libraries/`（默认 `data/libraries/`），点击刷新按钮，再从下拉列表选择。多个版本可以并存，选中立即生效，重启后记住选择；同名上传自动加编号。

切换后个人预设、固定词和编辑草稿保留。固定词按新词库重新识别，匹配到的参与共现统计，自定义词继续输出。已有任务和预取图片保留，新建候选使用所选词库。

上传接受 Pictide 成品统计库（tags、correlations、dataset），单个文件及解压后各支持最大 2 GiB；原始 Parquet 的处理见[数据准备](#数据准备)。词库选择的接口与实现见[需求记录](../issues/library-selection.md)。

## 正向生成与负向提示词

固定正向词与共现扩展参数在同一区域编辑；负向提示词放在默认折叠的独立区域，仅直接用于生图。两者保存到同一预设。负向词不参与 PMI 计算；共现扩展会按完整词项排除负向列表中的同名词，忽略大小写，空格与下划线等价。显式固定正向词保留；关键词屏蔽另按包含匹配。顺流旧组合含新排除的抽取词时重新生成合法组合，停泊已保持的组合不重写。

预览中只有正向词可查看和高亮两两相关性；负向词以普通文本独立展示，并保留复制按钮。

## 共现扩展

提示词候选根据 Danbooru 标签共现扩展生成。用户管理命名预设与固定正负提示词，词库是从数据集导入的只读数据；旧 JSON 标签库和槽位规则不再使用。数据来源为 `Shio-Koube/Danbooru-2026-parquet-metadata`，完整下载后在本地处理，不下载图片。设计、接口与 PMI 含义见 [共现候选说明](../issues/cooccurrence-candidates-v1.md)。

提示词页面提供「词库 / 编排 / 预览」。词库包含普通 general 类别中出现至少 100 次的标签，以及 general / sensitive / questionable / explicit 四个图片评级标签，按原始名称分页搜索；编排编辑固定词、数量上下限、PMI 阈值、最低共现次数、屏蔽关键词及连续变化预算。固定词可从匹配列表选择或输入自由文本，列表标记「词库词 / 自定义」，编辑后自动重新识别；未匹配词保留输出但不参与统计。预览中悬停或聚焦词项可查看与当前组合其他词的 PMI 和共现次数，并联动高亮；自由词无统计与已知词对未保留关系分别标记。

新词 t 必须对每个已有可统计标签 s 满足 PMI 阈值和最低共同次数。PMI 使用以 2 为底的对数，0 表示与独立预期相当，正值表示正关联；通过的词按 `2 ** mean(PMI)` 加权随机抽取；每次先在数量上下限之间等概率抽取一个整数作为目标，再尝试生成到该数量；无合格新词或搜索步数用尽时，直接返回当前已生成的提示词，可少于数量下限。数量包含固定正向词；固定词超过下限时，以固定词数量作为有效下限。不会为凑长度降低 PMI 或共现次数门槛；实际长度以生成结果为准。统计关联不是生成效果或无冲突保证。

## 随机、固定种子与连续序列

随机模式每次使用新种子；固定种子可复现；连续模式按序列种子与帧序号衔接，标签增加和删除各算一次变化，替换算两次，预算 0 保持原组合。连续帧在数量上下限与预算可达范围的交集内均匀抽取目标数量；预算是上限，无可行变化时可以保持上一帧。因此连续帧的长期长度分布不保证全局均匀。保留种子 / 帧序号生成后控制和搜索上限，取消槽位维度的锁定、保持帧数等配置。

## 词项与统计口径

数据集内部按空格拆分标签，下划线连接词；词库界面显示原始名称，不保存显示副本；推荐和生图输出在内存中将下划线转空格，标签间用 `, ` 分隔。固定自由文本按完整条目保存，不按内部空格拆分。

当前试用词库仅保留共现次数 ≥1,000 的关系，标签和预设保持。缺失关系表示未保留统计；预览显示“未保留统计”，次数显示“—”。裁剪结果和恢复位置见[极限裁剪记录](../issues/candidate-pair1000.md)。基础离线导入仍保留 ≥10 次的完整统计库。评级可作为固定正向锚点参与统计。运行时词库原名、词频、PMI、共现次数及来源保存在 `data/libraries/*.sqlite3`；个人预设和当前选择保存在 `data/db/candidate.sqlite3`，导入素材在 `dev/datasets/`。导入命令及分析依赖见 importer 的 CLI 帮助；导入在离线工具中执行，不放在启动或页面请求里。

## 数据准备

离线下载和导入使用 `backend.candidate.download` 与 `backend.candidate.importer`，运行模块的 `--help` 查看命令；源 Parquet、中间 SQLite 和成品库均放在 data 目录内。成品数据口径与文件布局见[存储参考](../reference/storage.md#候选数据)，设计与验证见[共现候选记录](../issues/cooccurrence-candidates-v1.md#离线导入)。处理完成后，在词库页面上传成品 SQLite，或复制到 libraries 目录后刷新选择，即可用于共现预览和漫游。
