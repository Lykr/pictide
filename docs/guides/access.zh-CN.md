# 局域网与主屏幕应用

[English](access.md)

[用户文档](../README.zh-CN.md)

让手机、平板或另一台电脑访问同一个 Pictide，继续浏览和漫游。

## 局域网访问

1. 电脑与手机连接同一个可信局域网。
2. 按电脑系统开启局域网访问：[Windows](setup/windows.zh-CN.md#局域网访问) · [Linux](setup/linux.zh-CN.md#局域网访问) · [macOS](setup/macos.zh-CN.md#局域网访问)。
3. 在手机浏览器打开电脑的局域网地址，例如 `http://192.168.50.50:8189`。

电脑上的 Pictide 需要保持运行；电脑 IP 变化后使用新地址。无需开放 ComfyUI 端口。

所有访问设备共用图片、设置和偏好，也都能生成和删除图片。请只向可信局域网开放，无需配置路由器端口转发。

## iPhone 主屏幕应用

用 Safari 打开局域网地址，依次选择「分享 → 添加到主屏幕 → 添加」；若出现「作为 Web App 打开」，保持开启。之后点击主屏幕图标，就能在独立窗口使用 Pictide。

主屏幕应用仍需要连接正在运行 Pictide 的电脑。电脑 IP 改变后，用新地址重新添加。

界面更新后，在 iOS 多任务切换器中彻底关闭 Pictide，再从主屏幕打开即可。普通更新无需重装；若需更新安装时的图标或窗口模式，再移除旧快捷方式并重新添加。
