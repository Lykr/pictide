## 大图操作与隐私

毛玻璃默认开启，标题旁可切换；各页网格与点击图片打开的大图面板共享状态，刷新后恢复开启。大图操作栏按「上一张、喜欢、下一张」居中排列，毛玻璃按钮位于右上角关闭按钮左侧，生成和喜欢页大图的图片信息统一放在左下角，不展示图片删除和下载按钮。大图左右切换图片，↑ 喜欢，空格切换毛玻璃，下方向键不执行操作；也可进入自动隐藏操作栏的沉浸模式，Esc 先退出沉浸，再关闭大图。漫游图片也不展示原图下载按钮，信息面板保留提示词 JSON 下载。
