# 漫游

[English](roam.md)

[文档导航](../README.zh-CN.md)

不用先想好要看什么，也能开始漫游。Pictide 会为你准备图片，无需手写提示词；遇到喜欢的画面就留下反馈，逐渐找到自己的方向。

## 开始浏览

完成[生图 API 接入](getting-started.zh-CN.md)后，在「设置 → 漫游」选好生图 API，回到漫游开始。用下一张继续探索，点击喜欢或不喜欢表达偏好，再次点击可撤回。评价会影响后续推荐，已经准备好的图片可能暂时延续原来的方向。

自动预取会提前准备后面的图片，减少等待；设为 `0` 时，点击下一张再生成。切换到新的云端生图 API 后默认关闭预取，可按需要开启。

## 换一种探索方式

在右上角「漫游选项」选择：

- **漂流**：每张重新组合提示词，发现更多可能。
- **顺流**：从当前组合逐步变化，沿着眼前的方向继续。
- **停泊**：保持整组提示词，用不同随机种子看看同一描述的其他画面。

「偏好范围」选全部时从完整词库探索，选喜欢时从已喜欢图片的标签中抽取。推荐力度默认使用标准；想更多围绕已有偏好浏览时，可以试试强力。

## 锚点

想保留眼前的某个元素，打开图片右下角的锚点，点选提示词，或输入自己的描述。它会带到之后的漫游中，其他内容仍可变化；生成效果取决于模型。

编辑后点击下一张，沿新方向继续。锚点会自动保存，下次回来仍可使用；取消选中即可移除。带锁的固定词来自[预设](prompts.zh-CN.md#词库与预设)，需要到提示词页修改。停泊保持整组提示词，切换到其他方式后可编辑锚点。

## 浏览与自动播放

想放松浏览，可以开启自动播放，并在漫游选项里调整每张的展示时间。生成尚未完成时会等待；喜欢一张图会暂停，进入下一张后继续播放。离开漫游会暂停播放。

方向键 ← / → 切图，↑ / ↓ 逐级调整不喜欢、未评价、喜欢。沉浸模式让图片占满屏幕，等待时左上角显示加载环；打开锚点浮层，就能继续引导后续图片。毛玻璃开关只影响显示，原图保持清晰。

漫游会记住上次看到的位置。想保留的图片请点喜欢，未喜欢的旧图会按[清理设置](settings.zh-CN.md)处理。
