# 生成

[English](generate.md)

[文档导航](../README.zh-CN.md) · [提示词与预设](prompts.zh-CN.md) / [喜欢](liked.zh-CN.md)

「生成」用于手动或按预设生图，结果在独立图片区域浏览和评价，不进入漫游列表或漫游缓冲计数。喜欢的图片也会汇集到[喜欢](liked.zh-CN.md)。

## 批量生成与种子

「生成」页分别设置「每次数量」与「生成次数」（均为 `1`–`10`，默认 `1`）。例如每次数量 `2`、生成次数 `3`，一次提交创建 3 轮、共 6 个独立任务，沿现有队列顺序执行。开启候选自动生成时，每轮重新抽取一次提示词，并按生成后控制更新候选种子与序列帧；同一轮内共用该轮正负提示词。固定控制保持不变；手动文本或关闭自动抽取时各轮沿用当前文本。标签库和后端配置在提交时冻结，后续编辑不改变已入队任务。

ComfyUI 工作流支持图像种子时，`-1` 使每个任务独立随机；指定种子时跨轮逐张递增，并在种子上限安全回绕，提交成功后输入框显示下一次种子。未绑定种子的工作流仍使用自身设置。全部轮次一次进入本地任务队列，关闭网页不停止已提交任务；应用重启后，待执行任务可继续，已发送请求能否恢复取决于后端。OpenAI Images 与 Gemini 不支持确定图像种子和负向提示词；请使用负向为空的文本或预设，由服务控制图像随机性，本地候选种子仍控制抽词。云端不确定提交不会自动重发，每个新生图请求都可能产生服务商费用；候选生成失败或剩余队列容量不足时整批拒绝。任务队列最多保留 100 个待处理任务，多次提交共用容量。

数量表示生图请求次数（ComfyUI 为工作流执行次数）：默认单图工作流执行 N 次得到 N 张；自定义工作流若每次输出多张，所有输出均会保留，最终图片可能多于 N 张。整批通过容量和幂等检查后一起入队，剩余容量不足时不创建部分任务；网络重试复用原请求 ID 和整批输入。

## 浏览生成结果

生成结果采用缩略图网格，悬停或键盘聚焦显示喜欢按钮，触屏直接显示。点击图片打开大图。毛玻璃、图片信息、快捷键和沉浸模式见[图片浏览](images.zh-CN.md)。

旧版手动生成图片归入生成区，已有图片、提示词和评价保留，继续遵循统一的[历史清理设置](settings.zh-CN.md)。

## 清空生成结果

标题旁一键清空作用于全部生成结果：未喜欢的图片及同名提示词 JSON 从本地清除，喜欢的图片仅移出生成结果，继续保留在「喜欢」。任务历史、ComfyUI 远端输出和漫游图片保留。操作不能撤回；文件被占用时沿用已有待删除队列重试。新生成的图片继续进入网格。
