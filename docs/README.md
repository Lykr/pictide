### 需求与功能记录

[需求目录](issues/README.md)按候选、推荐、漫游、界面和任务分类保存设计决定与验证记录。它们保留历史版本语境；当前使用看指南，接口看 API，职责看架构。

### 文档维护

README 用户指南在前，开发者入口在后，通过链接展开技术内容。入口只保留摘要和下一步；使用步骤放 `guides/`，接口与数据细节放 `reference/`，架构细节放 `architecture/`，需求与交付记录放 `issues/`。一个规则只保留一个当前说明，其他页面链接引用；专题页先说明用途，再展开细节。行为变更同步对应主题，旧决定留在需求记录并标明历史语境。
