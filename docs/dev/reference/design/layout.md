# 布局与交互

[设计规范入口](../../design-system.md) · [开发流程](../../development.md)

## 布局与响应式

词库页将选择词库、上传和刷新组成同一行管理工具栏，标签搜索独立置于下一行并占满内容宽度。窄屏下管理控件保持同组，选择框自适应剩余空间，文件名过长时省略；沿用共享控件尺寸与间距。

普通漫游和沉浸模式、生成结果页与生成大图均可按空格切换对应区域的毛玻璃；漫游与生成分别维护状态，各自的页面开关、浮栏及大图保持同步。按钮提示和 `aria-keyshortcuts` 标明空格。输入、弹窗、组合键和长按重复不触发页面级快捷键，大图使用自己的按键处理，避免切换两次；切换时阻止默认滚动或误触喜欢按钮。

喜欢页使用共享 Select 选择“最新优先／偏好评分”，与标签筛选放在同一工具栏，悬浮提示随当前排序方式切换，仅鼠标悬停显示，关闭菜单恢复焦点时不自动弹出；评分模式在毛玻璃按钮之前提供图标刷新按钮，外框尺寸、圆角、边框及内边距与毛玻璃按钮一致，悬浮提示显示上次成功手动刷新时间，加载状态沿用现有组件。评分排序的加载更多按钮使用中性“加载更多”，不称“更早图片”。

喜欢页复用生成结果的自适应网格与大图浏览组件，保留各自的数据和毛玻璃状态；不展示生成任务状态、清空结果或后端配置入口。点击缩略图进入大图，支持左右切换、信息及沉浸模式；网格状态下方向键不操作隐藏的漫游图片，空格切换喜欢页毛玻璃。

喜欢页取消喜欢时复用共享 AlertDialog 二次确认，说明图片将移出喜欢页并受自动清理规则影响；取消或 Esc 保留喜欢，确认后才提交反馈。等待确认期间锁定当前反馈及切图，避免重复弹窗；方向键喜欢保持幂等。

漫游与生成的图片信息面板复用同一组字段：面板标题右侧放提示词 JSON 下载；图像种子、正向提示词、负向提示词统一使用上方标题与右侧复制图标、下方内容区的布局；未知种子或使用工作流种子设置时禁用复制。内容区使用柔和背景与等宽字体，长文本独立滚动，窄屏自动换行。复制成功后原按钮短暂显示勾选图标及“已复制”无障碍标签，失败在原按钮提示，避免额外常驻状态文字；空提示词禁用复制。

所有普通栏目复用 `.workspace-content`：以喜欢页面为基准，容器最大宽度 1200px、水平居中、桌面内边距 24px，视口不大于 1024px 时为 16px。漫游与提示词不额外扩大或缩窄页面内容；提示词各子页继承同一左右边界。页面保留滚动条空间，切栏不因滚动条出现而偏移；图片沉浸模式继续全屏。

桌面侧栏统一为 144px，保留图标与短名称，不随大屏增宽；不大于 768px 时使用横向导航，主要空间留给内容。

页面按任务分区：漫游突出推荐图片与方向键操作，生成页左侧生图表单、右侧独立生成结果，提示词页管理词库与规则，设置页按通用、漫游、后端和历史分类。导航名称必须与内容标题相符；工具集中在各区标题附近，避免同一操作多处重复。

生成页不展示顶部操作通知，生成按钮下方也不展示最近任务状态卡；任务进度在生成结果区与设置历史中查看。生成按钮旁提供 outline「取消待执行任务」按钮，仅取消生成页待执行任务，使用原按钮反馈取消数量或失败原因；提交与取消相互禁用，避免同时操作。提交生图、抽取提示词和刷新规则配置在原按钮显示加载图标与结果，成功后短暂显示勾选并恢复；失败或提交结果待确认保留在按钮上，完整原因及安全重试说明通过共享 Tooltip 和可访问状态提供。提交成功只表示任务已接收，生成进度仍在结果区展示；后台同步失败保留在结果区，不转成顶部横幅。

生成页的共现候选区按两列排列「生成预设 / 抽取模式」；预设刷新图标与标题同排。固定种子和连续序列按「数值 / 生成后行为」成对排列，字段标题与控件间距统一，输入和下拉均使用默认 36px 高度；仅展示当前模式需要的参数。搜索设置保留折叠；自动抽取开关与抽取提示词按钮同排，窄屏空间不足时自然换行。不增加嵌套卡片或分割线，保留现有控件 ID、表单校验和控制器行为。

每次数量与生成次数并排使用带整数上下限的 Input，均默认 1、范围 1–10；帮助说明逐轮按共现预设生成、轮内共用提示词、生成后控制、跨轮图像种子、顺序执行与工作流多输出。生成结果采用紧凑网格，少量图片不拉成巨幅；生成与喜欢页的缩略图等比例居中填满卡片（cover），超出部分裁切，大图继续完整展示（contain）；喜欢图标悬停或 focus-within 展示，触屏常显，缩略图不附带常驻种子与工具底栏。结果标题右侧放毛玻璃及一键清空图标，毛玻璃默认开启且与大图共享状态，图片首次显示即模糊，刷新恢复开启；与漫游毛玻璃分别管理。点击图片打开官方 Dialog 大图，左右切图、↑ 喜欢、空格切换毛玻璃，下方向键不执行操作；操作栏按上一张、喜欢、下一张居中排列，毛玻璃按钮位于右上角关闭按钮左侧，生成和喜欢页大图的图片信息统一放在左下角，不展示图片删除和下载按钮。漫游也移除原图下载入口，信息面板保留提示词 JSON 下载。输入、辅助浮层与忙碌状态保留自身键盘行为。

生成与喜欢大图的沉浸布局与漫游一致：右上悬浮菜单放毛玻璃和退出沉浸模式，底部放上一张、喜欢、下一张；漫游右上菜单在毛玻璃前增加播放/暂停（保留时间进度环），底部另保留不喜欢。使用相同的按钮尺寸、间距和毛玻璃 Toggle 状态；Esc 先退出沉浸，再关闭浮层。切图保留隐私状态，分页等待与缓存重读期间保留画面，确实无图才关闭。清空按钮的可访问名称和提示明确区分“未喜欢删除，喜欢移出生成页”；操作失败在当前大图或结果区可见，重复操作在忙碌期间禁用。窄屏表单和网格上下排列，工具保持可触达。生成与漫游分别维护图片列表、分页和展示 DOM，跨来源的喜欢图片仍汇总到喜欢页。

漫游沉浸模式的上下键与独立应用上下滑动共用评价反馈：确认成功后，在画面水平居中、约 68% 高度显示图标及短文字，轻微弹入并淡出，持续约 900ms；取消评价也展示对应结果。提示不拦截触摸、不唤起隐藏操作栏，切图时清除；请求失败不显示成功反馈。系统减少动态效果时保留同位置静态短提示。

### 提示词预览

预览页按“生成控制 → 结果 → 折叠报告”组织。模式选择与搜索设置、预览动作同排；提示词种子及生成后行为为一组，连续帧序号及生成后行为为另一组，窄屏按组堆叠。搜索上限默认折叠。状态、种子和连续变化信息放在结果上方；正负提示词分区使用柔和底色与同列复制按钮，文本区随内容增高，不为短结果保留固定空白。正向词保留相关性操作，负向词保持普通文本；生成报告默认折叠。

### 设置

设置分类按「通用、漫游、后端、历史」排列，沿用同一内容宽度（780px）与表单节奏：字段标题行至少 24px，标题至控件 8px，同组字段 16px，分区 24px；双列在窄屏转为单列。复用 `.settings-field` 与 `.settings-stack`，避免借助 label 外边距排列整个表单。主题和漫游分段控件左对齐，单位放在 InputGroup 内；数据路径使用次级标题与等宽正文，长路径可换行。保存操作统一在表单右下，测试连接留在左侧。折叠区域保留轻量标题，不增加卡片套层或装饰分割线。

设置分类使用横向 Tabs（通用、漫游、后端、历史），保留页面标题「设置」，分类内容不重复显示标签页标题。漫游配置预取数量、生图后端和候选词库，规则及业务状态由服务端管理；漫游页面不展示预取数量、进度等常驻提示，不增加生图表单，仍保留下一张等待动画和操作错误。顶部只显示后端可用状态，不重复放置设置入口；可用表示至少一个已保存后端通过只读连接预检，读取配置和保存后检查，不新增定时探测。

漫游页右上按「播放/暂停、毛玻璃、沉浸模式、漫游选项」排列四个 32px 图标按钮，播放保留时间进度环，毛玻璃与沉浸入口直接可用；共享 Popover 包含展示时间、偏好范围、漫游方式和推荐力度，普通和沉浸底部操作栏提供锚点入口、切图与评价。菜单宽度按标签与控件的内容自适应，并受视口宽度限制、内边距 12px，展示时间标题与带“秒”单位的 InputGroup 同行；输入回车或失焦保存，不显示独立保存和播放按钮。偏好范围、漫游方式和推荐力度复用共享 ToggleGroup 单选，可在当前菜单和设置 → 漫游中调整。菜单收起时不可见控件不进入 Tab 顺序，关闭和退出沉浸后焦点回到入口。设置 → 漫游同样提供自动播放间隔、偏好范围与漫游方式；两个入口共用已保存配置，局部修改不覆盖其他字段草稿。改变范围、方式、后端或候选预设时暂停自动前进和旧窗口合并，保存后按产物修订重读当前及后续窗口，再恢复播放意图；旧请求回包不得合回窗口，失败保留原选择和当前图片。空喜欢词池仅在用户等下一张时结束加载并提示，后台补图不反复弹出通知。

后端设置沿用上述统一字段节奏与默认 36px Input/Select；标题工具采用 icon-xs，不撑高单侧标题。节点参数面板使用共享 Collapsible，默认折叠，切换后端时重新折叠；点击透明的“箭头＋标题”展开，悬停与展开状态均不增加胶囊底色，保留键盘焦点环；JSON 切换、文件导入、读取默认节点参数或参数校验失败时自动展开。折叠保留草稿与表单控件，JSON 和导入操作仍在标题右侧。节点参数按节点分组，单字段占满一行，多个参数两列排列；输入绑定集中左侧，输出节点右侧，窄屏转单列。保留一层节点参数边框，不增加分割线。JSON 导入使用向下进入托盘的 Download 图标，名称仍为“导入 ComfyUI API 工作流 JSON”；它触发本地文件导入，JSON 按钮继续切换参数/源码视图。

漫游设置中的「历史图片数量上限」与预取数量并列，使用整数 Input（`0`–`100000`，默认 `0`）。HelpTip 说明关闭值、当前图片之前全部历史计数、当前与预取不计、最早优先、未喜欢删除本地图片和 JSON、喜欢只从漫游隐藏以及生成页不受影响；删除后果可通过明确的帮助按钮查看。保存后根据产物修订重读图片和观看位置，保留其他设置草稿。

| 视口 | 布局原则 |
| --- | --- |
| 大于 1024px | 桌面分栏；主要内容弹性占满可用空间 |
| 768–1024px | 收紧侧栏与间距，减少同时并列的次级区域 |
| 640–768px | 主要面板改为上下排列；导航允许横向滚动或换行 |
| 不大于 640px | 单列，表单工具与操作按钮换行；弹窗适应屏宽 |

Flex / Grid 内容列设置 `min-width: 0`，长 ID、路径和提示词适当换行。页面不出现意外水平滚动，图片不挤压表单；确实需要横向阅读的代码区独立滚动。调整断点应同时检查 Feed、编辑器与弹窗。

图片信息面板在图像种子之前展示“偏好评分”，帮助问号紧接标题右侧，共享一位小数及加载／暂无区分／暂无法评分状态；原始分数、历史范围和相对刻度说明收进 Tooltip，接口与计算规则见 [偏好评分](../../issues/image-preference-score.md)。

## 键盘与可访问性

- 所有可交互控件可用 Tab 到达；保留清楚的 `focus-visible` 焦点环，不全局移除 outline。图片浏览容器为键盘快捷键接收程序焦点，自身不显示外框；内部按钮、输入框和分隔线保留焦点提示。
- 原生按钮使用 `button`；导航使用链接。图标保持统一尺寸和描边，不用表情符号充当核心操作图标。
- 图片视图方向键：左键上一张、右键下一张；漫游上／下键逐级提高／降低评价（不喜欢 ↔ 未评价 ↔ 喜欢），两端保持，忽略按键自动重复。独立应用漫游图片上／下滑使用相同规则，一次手势只调整一级；普通浏览器保留纵向滚动，左右滑动切图不变。按钮直接选择／撤回评价。生成／喜欢大图上键喜欢，下键不执行操作。输入框、可编辑区域、选择控件和弹窗中不触发全局快捷键；沉浸模式仍保留这些操作，Esc 退出。
- 动态状态使用合适的状态区域；错误信息及时可见，避免每次轮询重复播报。
- 小字号与辅助信息仍需清楚可读；移动端主要操作保持足够点击面积。

## 移动端与触屏

- 手机底部五栏固定展示漫游、生成、喜欢、提示词和设置，保留底部安全区；导航行 48px，顶栏内容行 44px，横屏顶栏 40px，安全区额外计入。桌面及主屏幕应用使用 `100dvh` 固定外壳与栏目内部滚动。普通 iPhone WebKit 浏览器使用真实文档滚动：外壳自然排布、顶栏 sticky、底栏 fixed，内容底部预留导航高度；切换栏目保存和恢复文档滚动位置，弹窗及沉浸期间锁定文档。地址栏收起需要浏览器响应用户滚动及足够的内容高度，短页不保证收起，不通过空白占位或程序滚动模拟隐藏。
- 手机漫游图片与工具栏使用两行 Grid；图片绝对定位于明确的图片区域中，避免百分比图片高度撑大容器。漫游图片区取消单侧滚动条留白，左右使用相同安全区边距；主屏幕模式填满剩余可用高度，普通浏览器使用 2:3 图片框且不超过 72svh；Grid 显式使用单个弹性列，图片框宽度固定占满该列，最大高度只约束高度，避免 Safari 因比例约束收窄图片框并在单侧留白；原图在框内居中 contain。图片卡片统一圆角裁切及轻边框，模糊不外溢，工具栏不覆盖普通图片区域；锚点收起时沉浸工具栏保持悬浮。普通图片底部操作栏在桌面和手机均使用左右对称的弹性列，中间切图与评价按钮组按整个图像框宽度居中，信息按钮单独放在左列，漫游锚点入口放在右列，不挤偏中间按钮组。
- 窄屏或触屏设备的主要控件点击区域至少 44×44px，保留 Luma 图标大小、圆角和配色。文本/数值输入使用 16px，减少手机聚焦后的自动放大，不禁止页面缩放。
- 手机表单、固定正负词与预览采用单栏；图片网格保留两列，缩略图喜欢操作直接可见。选择菜单受视口高度限制，可滚动且不会横向挤出屏幕；漫游选项内容在空间不足时换行。
- 漫游、生成和喜欢大图支持单指左滑下一张、右滑上一张，仅图片区域接收手势；竖向起势、多指缩放、控件点击不切图。键盘行为与各自的较旧/较新分页规则保留，滑动本身不产生喜好反馈。
- 沉浸模式在桌面和触屏均显示右上角悬浮菜单，避开顶部与右侧安全区；锚点收起时与底部操作栏一起唤醒、闲置约 2 秒后隐藏，鼠标悬停或键盘聚焦任一栏时保持显示。隐藏控件同时退出焦点与无障碍顺序，退出后焦点返回原入口。触摸不作为鼠标悬停，帮助仍可点按查看。独立应用沉浸画面仅在短暂点按松手后唤醒菜单，上下左右滑动、多指或取消手势均不唤醒；复用同一沉浸控制器覆盖漫游及生成／喜欢大图。
- 图片信息和预览共用复制帮助方法，优先 Clipboard API；局域网普通 HTTP 下回退浏览器复制命令。浏览器拒绝时保留按钮错误反馈与可选择文本。

## 主屏幕应用

- `web/public/manifest.webmanifest` 定义安装身份、名称、根路径范围及 `/#feed` 启动入口；通过既有 `/static/ui/` 提供，不新增后端 API。清单位于静态目录，但启动路径和 scope 必须指向应用根路径，避免安装后打开静态文件目录。
- `web/index.html` 提供清单、iOS standalone 元信息与 `apple-touch-icon`。`web/public/icons/` 的 180 / 192 / 512 PNG 由正式浪形 P 矢量轮廓的相同曲线导出，源资源见[图标记录](../../issues/brand-icon.md)，实际运行资产提交 Git；图标有不透明底色，由系统裁切。
- `display-mode: standalone` 恢复固定外壳与栏目内部滚动，不使用普通浏览器的文档滚动布局；顶部/底部继续使用现有安全区。主题渲染同时更新 `theme-color`，与显式黑白或跟随系统保持一致。
- 本版不注册 Service Worker，不缓存 API、图片或旧构建；主屏幕模式仍在线连接 Pictide。不能将独立窗口或安装元信息称作已支持离线生图。

## 界面语言

产品文案通过 web/src/i18n/index.mjs 的 t / tr 调用，React 与 DOM 控制器共用词典，禁止在 UI 中新增未接入的可见文案。简体中文原文作为消息键，英文按页面领域维护在 messages/en/；动态值使用具名占位或 tr 模板的位置占位，译文可改变词序。

默认跟随浏览器首选语言，简体中文以外未支持的语言使用英文；手动选择优先。用户内容、实际提示词、标签原名、模型／工作流技术标识直接展示原文。日期和数字使用当前 locale；英文文案允许自然换行，表单值与页面状态不随切换重置。设置与新增语言步骤见 [国际化](../../issues/i18n.md)。


漫游折叠菜单按标题和选项的内容宽度自适应，保留 320px 的常规最小宽度，并受视口和 Radix 可用宽度限制；左右至少留 12px。空间充足时标题与按钮同排、选项靠右；窄屏允许整组选项换行，超长标题自然折行，避免固定宽度造成翻译后的额外换行或横向溢出。

独立应用窗口（display-mode: standalone）隐藏顶部 Pictide 品牌栏，由各栏目的现有标题承载定位；顶部保留系统安全区，释放品牌栏占用的高度。该规则按显示模式生效，适用于 iOS、安卓和桌面独立窗口；普通浏览器保留品牌栏。

图片之间切换可使用约 180ms 的图片透明度淡入，复用共享 image-transitions 处理；首图、同图反馈和普通重绘不播放，操作栏与毛玻璃不参与动画。遵从通用设置开关与系统减少动态效果，快速切换取消上一段动画。

## 漫游锚点编辑区

图片底部左侧放信息、右侧放锚点，左右对称，锚点采用锚图标和已选数量角标，中间切图与评价按钮组保持居中。展开使用同一卡片内的 Grid：桌面图片在左、锚点在右，支持拖动分隔线调整比例并在本机保存，分隔线支持方向键及 Home/End；手机图片在上、紧凑词条在下，默认编辑区 112px（不超过 25dvh），按加号展开输入后为 156px（不超过 32dvh），添加成功收起输入；完整图片 contain 于剩余区域，锚点词项独立滚动，编辑区与图片同屏。普通和沉浸模式复用同一组件、输入草稿与展开状态；点选、保存和切图均保持展开，切图更新可选词，选中锚点保留。手机隐藏面板标题、重复数量和帮助，固定词只保留锁图标，来源通过提示说明。通过入口或桌面面板关闭按钮主动收起，关闭按钮将焦点还给入口。

桌面普通模式展开与收起锚点共用图片区域高度，工具栏按实际内容计算高度，切换时卡片和图片区域高度保持一致；拖动分隔线只调整左右比例。沉浸模式展开锚点时保持控件可见，编辑区内的触摸与输入不触发画面手势或图片快捷键。收起后恢复既有闲置隐藏行为。锚点保存、停泊只读及预取行为沿用[漫游指南](../../../guides/roam.zh-CN.md#锚点)。

信息浮层入口位于图片左下角，锚点面板入口位于右下角。打开锚点收起已有信息浮层，查看信息保留锚点及其草稿。沉浸模式的信息浮层挂在当前图片卡片内，保持可操作；Esc 先关闭信息，再退出沉浸。
