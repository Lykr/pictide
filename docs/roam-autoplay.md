# 漫游自动播放（已确认）

## 架构

浏览器负责播放状态与单次切图计时，复用现有漫游导航、图片加载事件和下一张等待机制。配置沿用浏览器 → Host → Application → RoamSettings/SQLite，生成仍由原预取链路处理。候选、推荐、任务之间不新增直接调用；不新增服务端定时任务或独立生成循环。

## 调用与数据流

漫游图片操作栏在喜欢按钮左侧增加一个播放/暂停键，两种图标状态复用同一按钮，普通与沉浸模式共用。漫游页标题旁用现有 shadcn Popover + 数字输入设置每张展示秒数。

播放时，在当前图片实际加载完成后等待指定时间，再执行既有下一张操作。若下一张尚不存在，只保留一次等待意图，通过原 demand/预取请求生成；图片准备好后自动前进，加载完成重新计时。等待期间不叠加定时请求、不跳过迟到的图片。播放按钮以环形进度围绕暂停图标显示当前图的已展示时间，普通、沉浸与选项菜单共用一个计时；等待下一张时保持满圈，暂停恢复播放图标。环形动画复用计时起点与时长，不另开逐帧状态更新。自动播放时点击喜欢或按上方向键，立即暂停当前图片并显示播放图标；重复操作或已喜欢图片也保持暂停，不重置计时。用户主动进入下一张后恢复自动播放，新图加载完成才重新计时；没有下一张时等待生成，期间保持暂停，查看上一张不恢复。手动暂停、离开漫游或切到后台会取消这次恢复意图。喜欢反馈继续幂等，输入和弹窗内不触发。暂停取消自动播放的等待意图但不取消已派发任务；手动切图重新计时。离开漫游、页面隐藏、页面关闭、刷新默认暂停；预取暂停不禁用已有图片的播放；主动请求新图片遇到生成暂停或图片读取失败时停止播放并沿用错误提示。网络暂时失败继续复用既有页面事件恢复。连接恢复及页面重新可见时重读漫游设置，刷新播放可用状态，避免旧暂停状态残留。

## 接口

现有 GET/PUT /api/settings/roam 新增 playback_interval_seconds（整数 1–600，默认 5），存于所选 data/pictide.sqlite3。PUT 支持只提交此字段，保留预取数量、历史上限、后端、预设和 epoch/暂停状态；原完整设置保存保留当前播放间隔。返回继续包含现有字段并新增此字段，通过既有 roam_settings 事件同步间隔。播放/暂停本身只属当前页面，不保存到服务端。修改间隔后，当前图按新间隔重新计时。

## 验证

少数冒烟验证计时、无下一张等待并继续、暂停取消等待且不撤销任务、图片加载完成才计时、手动切图重置、离开/隐藏暂停。HTTP 验证间隔持久化和单字段保存不影响原配置/epoch/暂停。类型检查、构建及隔离浏览器验证；模拟后端，不派发真实 GPU 任务。发布前备份并告知重启。

已验证：3 个前端计时冒烟、2 个 HTTP 设置冒烟、类型检查和构建通过；隔离浏览器验证了自动切图、等模拟出图后继续、等待时暂停不切迟到图、刷新保留间隔但暂停、沉浸按钮共用及离开漫游暂停。未派发真实 GPU 任务。

播放可用性修复验证：模拟预取暂停且有已保存图片时，播放按钮可点击并自动切图；模拟断线改间隔后重连，无需刷新自动同步新值。未添加设置页控件。已有 3 个播放冒烟、类型检查与构建通过，验证未配置生图后端。

喜欢后暂停验证：覆盖重复喜欢不重置、上一张保持暂停、下一张加载完成后恢复、等待时取消自动前进，以及手动暂停／离开页面取消恢复；普通与沉浸共用同一播放状态。
