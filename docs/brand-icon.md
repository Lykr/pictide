# Pictide 图标

- 完整图标：[pictide.svg](../web/public/icons/pictide.svg)，深色圆角方形与白色 P。
- 透明符号：[pictide-mark.svg](../web/public/icons/pictide-mark.svg)，通过 currentColor 着色，内联时可跟随界面主题。

P 的内部留白是一道流动的水面，呼应画流与漫游。使用填充路径，无字体、图片、滤镜或外部依赖；256×256 viewBox 可任意缩放。

本次提供矢量设计源文件；浏览器、PWA 的 PNG 图标和页面品牌标记继续使用当前资源，确认采用后统一替换。
