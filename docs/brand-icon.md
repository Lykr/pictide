# Pictide 图标

- 完整图标：[pictide.svg](../web/public/icons/pictide.svg)，深色圆角方形与白色卷浪。
- 透明符号：[pictide-mark.svg](../web/public/icons/pictide-mark.svg)，使用 currentColor，内联时可跟随主题。

从卷浪照片的厚实水墙、偏心浪洞和内勾走势提炼整体轮廓，让一道连续的卷浪形成自由的 P 字形。用粗细变化表达流动，以黑白轮廓保持简洁。

主体只有一条闭合填充路径，完整图标另有圆角背景。256×256 viewBox，无字体、图片或外部依赖，已查看 16–64px 预览。

当前为矢量设计源文件，应用已发布的 PNG 和页面品牌标记尚未替换。
