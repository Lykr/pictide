# Pictide 图标

- 完整图标：[pictide.svg](../web/public/icons/pictide.svg)，深色圆角背景与白色符号。
- 透明符号：[pictide-mark.svg](../web/public/icons/pictide-mark.svg)，使用 currentColor，内联时可跟随主题。

依据用户提供的草图整理：外圈撑出 P，内侧浪头回卷，竖干随水势收成尖尾。保留草图的形态和比例，整理曲线衔接与粗细过渡；负形形成浪洞。

主体是一条闭合填充路径，完整图标另有圆角背景。256×256 viewBox，无字体、图片或外部依赖，已核对草图对照及 16–64px 预览。

当前为矢量设计源文件，应用已发布的 PNG 和页面品牌标记尚未替换。
