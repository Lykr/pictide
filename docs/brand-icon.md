# Pictide 图标

- 完整图标：[pictide.svg](../web/public/icons/pictide.svg)，深色背景、白色 P 边界。
- 透明符号：[pictide-mark.svg](../web/public/icons/pictide-mark.svg)，使用 currentColor，内联时可跟随主题。

背景通过 P 内侧的透空区域形成卷浪，P 作为外围边界。外边界减薄并控制主线重，主干和上下收口保持平直，浪尖收细；背景圆角同步收敛。

主体为一条采用 evenodd 填充的复合路径，浪形是实际透空，不额外叠加背景色图案。256×256 viewBox，无字体、图片或外部依赖，已查看 16–64px 预览。

当前为矢量设计源文件，应用已发布的 PNG 和页面品牌标记尚未替换。
