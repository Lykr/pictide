# Pictide 图标

- 完整图标：[pictide.svg](../web/public/icons/pictide.svg)，靛蓝圆角方形、纸白 P 与浅蓝水纹。
- 透明符号：[pictide-mark.svg](../web/public/icons/pictide-mark.svg)，单色填充，通过 currentColor 着色；内联时可跟随主题。

以浮世绘浪花的卷曲、钩状浪尖和飞沫为视觉方向，P 的内侧形成翻卷浪花，下部水纹沿字母回旋。保留整体 P 的辨识度，使用平涂色块。

全部由 SVG 填充路径构成，无字体、图片、滤镜或外部依赖；256×256 viewBox 可任意缩放。已检查 16–64px 预览。

当前为矢量设计源文件；浏览器、PWA 的 PNG 图标和页面品牌标记继续使用当前资源，确认采用后统一替换。
